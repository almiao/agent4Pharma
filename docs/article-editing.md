# 人工图文审稿与定点修改

2026-11-05，ADR-110。审稿定稿中的“人工审稿与修改”打开完整图文工作区，绑定用户正在看的准确渠道包和稿件；不会静默切换为同选题另一稿。历史版本只读，明确切换到最新版本后才可修改。

## 操作

工具栏的“手动编辑”打开标题、正文和图注表单，支持直接改字及增删段落。图片继续复用准确包内的原图；可按段落编号调整位置，段号包含小标题。正文沿用纯文本与 `## ` 小标题格式，不接收任意 HTML。

手动修改须点击“保存为新版本”，保存不调用模型，不自动排队审核。取消有未保存内容时须确认放弃，保存失败保留表单内容；页面刷新会提示未保存修改，但不提供跨刷新草稿恢复。修改涉及已有关键表述时，须在“关键表述与证据关联”确认对应的新正文原句，或清空移除该关联；至少保留一处，原始证据及逐字引文不可在此改写。关联检查只保证原句和证据身份一致，最终内容由人工审阅确认，不再调用模型复核。

手动保存校验准确包、稿件、图片数量、段落位置、引文和任务空闲状态；渲染后提交前再次校验源版本和故事修订，拒绝并发或过期保存。相同源包和相同内容的重复提交返回同一新版本。历史只读；手动与DSH修改共用原子版本保存、撤销及人工定稿规则，新包不继承旧批准。

来源列表的显示与证据存档分开：`excluded_source_ids` 按准确稿件内的证据身份隐藏文末来源链接，不删除证据、引文或图源。此设置随图文版本冻结，后续人工/DSH改稿和重新排版继承；撤销恢复目标版本的显示设置。旧包不添加空字段，已有批准指纹保持不变。当前表单只提供文字和图片位置编辑；来源显示控制由保存接口接受，不按标题猜测关联。

选中标题、正文、小标题或图注后，立即加入右侧引用卡片；输入意见不清空选区引用。可引用多处，点击图片或键盘聚焦后按Enter/空格加入图片引用。快捷模板只填入意见，点击“交给DSH修改（调用模型）”才授权执行。无选区时须在意见中指明位置，不提供整篇重写入口。

DSH自主判断是否需要读绑定论文原文/译文或web_search公开资料。仅开放绑定证据、已登记网页和有界图目录/看图，不加载作者研究底稿，不提供Shell或任意文件/URL工具。返回一个定点变更集，宿主校验后直接原子保存新的稿件和图文包。证据不足时允许解释未完成并不改内容，技术失败单独保留。

图文版本保留未改文字、原图字节及图片记录；新图须来自绑定论文且实际看过准确图块。支持标题/正文/图注改字、已有图片移动、删除与替换。正文增删段落时按唯一原文移动图片锚点；无法唯一定位须明确给出图片新位置。既有重点原句仍可唯一定位时保留强调，否则移除失效标注。不接受任意HTML或外部图片路径。历史模板使用当前固定宿主模板重渲染，不保证旧模板像素级一致。

新版本显示改动前后差异；“撤销上次修改”恢复完整图文为另一个新版本，不覆盖历史。后续意见基于新版本。切换历史不自动跟随最新稿，模型执行期间不能同时应用/撤销。请求UUID、准确包/稿件、选区和任务租约用于拒绝重复、过期或错位提交。

## 人工确认定稿

人工介入后的手动修改、DSH定点修改和撤销恢复均可直接人工确认定稿，不要求再次经过模型阅读评审或事实核验，不提供“完成修改并核验”按钮。保存只追加准确图文版本，最终由用户勾选已审阅并点击“确认定稿并进入交付”，不调用模型、不重新选图。自动采编中原有阅读评审和事实核验不变。

人工修改版仍校验准确编辑链、最新稿件、任务书、正文及公众号指纹，并拒绝同选题排队或运行中的任务。历史模型复核仅推进故事修订或要求返修、但没有改变任务书和准确稿件时，不再阻断人工确认；取消的选题仍不可定稿。自动制作包继续要求准确故事修订及模型通过报告。人工批准前不可导出或交付；旧批准不继承，撤销后也须重新人工确认。edit_pending保留为既有人工编辑版本标记，不再表示模型核验门槛；已存的人工编辑版本采用同一人工定稿规则，不补造模型通过报告。

## 执行过程

每次DSH任务有默认折叠的执行过程面板，展开才按游标增量拉取通用追踪事件。按时间顺序显示实际公开响应、模型/工具/MCP调用、参数、结果、失败和用量，支持调用树及原始记录。没有采集的数据明确为空，不补造内部推理。任务详情可继续停止/重试；折叠或离开页面不停止后台任务。

## 实现与接口

- content/article_editing拥有文字/图片修改请求和变更契约。
- workflows/article_editing负责编辑排队、准确选区及历史模式读取；article_product_versions统一准确包校验；article_product_editing负责图文合成、原子保存与恢复；human_package_approval负责人工定稿。
- 发布模块ChannelPackage保存edit_root_id/edit_parent_id/edit_pending；空字段不写入历史序列化，旧批准指纹保持原样。沿用JSON持久化，不新增数据库表。
- POST edit-state接受product=true；include_document=false仅轮询状态与轻量版本目录，不重复发送全部历史图片。
- POST edit-generate接受auto_apply=true；edit-restore恢复准确历史包；approve-package确认人工定稿。均位于/api/production/下。edit-review已退役，旧请求明确提示刷新并直接人工定稿，不再创建模型任务。已存在的历史核验记录与任务继续保留，不自动取消或重跑。
- POST edit-manual接受ManualArticleEdit（准确package_id/draft_id、完整title/body、按原图顺序的figures图注和段落位置、可选claim_texts/excluded_source_ids）；manual_article_editing协调人工保存，无模型凭证也可使用。claim_texts按原稿关联顺序提交，空字符串表示移除；excluded_source_ids未提供时继承，空列表恢复全部来源显示，仅可指定当前稿件证据身份。不接受新证据或任意图源。
- 旧冻结候选任务保留读取/接受契约，不把历史候选冒充已应用图文。

离线测试和浏览器隔离验证不能代表真实DSH修改质量；本次未授权真实模型冒烟。
