# 编辑改造对照验证

本方案尚未执行真实模型调用，不以离线契约测试冒充质量改善。

## 四组文字实验

先固定同一论文、任务书、资料起点、模型配置、技能快照与总预算。按独立新根运行，保留每阶段准确产物、失败和实际用量，旧生产记录不覆盖。

| 组别 | 唯一主要差异 |
|---|---|
| 基线 | 改造前冻结研究与写作规则 |
| 研究组 | 允许关键背景正文与主张边界交接，写作规则不变 |
| 写作组 | 使用基线完全相同的证据池，只改材料用途与取舍方法 |
| 组合组 | 同时采用研究与写作改进 |

研究组增加的网页必须记录URL、正文hash、获取范围与用途；不能将资料输入不同的结果称为纯提示词效应。对照工具权限、来源和费用采用准确运行快照，不在实验过程中偷偷切换。失败、超额和未成稿同样报告，不能只保留成功版本。

AutoDNA用于定位问题，至少再选方法评测、分子实验或资源工具等不同题材作留出验证。固定一篇多次返修不等于跨题材泛化。

## 盲评与评审器校准

隐藏版本名称，随机顺序呈现，人工按事实边界、技术理解效率、新闻价值表达、阅读体验比较，并引用准确段落说明理由。记录改进、退步、无明确差异及分歧，不按数字、加粗、图片或短段数量评分。

反例覆盖：简洁却误导、复杂但解释清楚、数字多但必要、格式漂亮却无主线。检查读者编辑能否指出具体障碍，以及是否误退好稿、删去关键条件。事实核验独立进行，不由阅读偏好替代。

## 图文单独对照

固定同一准确正文和原图，只改变重点标注及图文位置。检查390px和桌面预览的文字完整性、无横向溢出、图中文字可读及限定未被选择性弱化；微信真实粘贴效果需单独实机验证。明确区分程序验证文字未变和人工判断重点选择合理。

每组报告作者请求数、总/缓存/未缓存token、返修数、耗时和最终交付阶段，不只比较最后一次输入大小。真实调用需明确授权后执行，离线准备不自动启动生产队列。

## 局部返修候选回归

离线业务场景见tests/integration/test_revision_workspace.py：RR-04式跨页实验归属，局部替换、错误引文预检、暂停后跨任务恢复、候选回滚、准确版本提交、未改内容与独立审核交接。去重覆盖字符窗/页窗/批量定位、来源身份隔离、显式重读和新会话记忆重置。这些是确定性业务测试，不冒充真实模型质量实验。

真实模型对照使用scripts/replay_revision_workspace.py。先以--source-root、--source-task、--output-root准备隔离库；需复制完整稿件版本与审核历史以维持实际交稿约束。原任务输入和已保存资料增量保持冻结，新协议、指令、工具是实验变量。PDF在隔离目录重新校验，复用已显式启动的资料服务，不启动或下载依赖模型。默认不调用LLM；明确任务授权后加--execute-model，只执行一次作者任务；加--execute-review可显式执行最多两个独立审核节点，--execute-followup ID只执行本实验链中指定的一次排队作者返修，均不执行图文/交付或改写生产任务；--report-only只整理已有观测。

验收同时检查：是否真实提交、每次输出及总用量、已保存候选版本、修改diff、引用验证、问题处理是否符合原文、无关段落与引用是否保留、失败恢复是否复用已保存成果、后继是否仍为独立审核。初始上下文变小、机械预检成功或未触顶，任何一项单独都不能算业务通过。一次成功样本不能证明所有返修都会收敛。

具体任务、失败实验和结果保存在data/reports的实验目录中，本页不记录单次指标或生产切换状态。


活动窗口成本回归须保留失败或更贵的实验臂。累计token、非缓存输入、缓存输入、输出、摘要次数、估算费用和审核终点分别报告；不可把作者阶段节省当成已审核稿的节省。生命周期查询按准确父子链计入全部尝试，新增返修导致的费用不得排除。运行时执行文件/适配器hash与冻结策略进入通用观测；SDK初始化仅能证明接口可用，不能冒充真实压缩或生成质量验证。
