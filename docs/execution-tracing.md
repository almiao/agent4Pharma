# 通用执行追踪

当前契约为runtime.execution_trace.ExecutionIdentity和WorkflowObservation.execution，写入由ExecutionRecorder负责；持久化使用既有ObservationSink。业务只提供准确主体、Agent及调用输入，不能以观测替代产物成功校验。

新上下文清单与回执复用上述体系：`context_manifest` 独立保存每个公开载荷/模型输入版本，`context_delivery` 记录经过本会话身份与hash验证的SDK结果。三种状态及只读诊断入口见[节点上下文契约](production-context-contract.md)。缺回执的历史仍不关联，清单缺失不等于没有输入。

执行单元有稳定的trace_id/span_id/parent_span_id；kind区分workflow、agent、model、tool、mcp、event。同一单元的开始/结束使用同一span_id，turn/step/call_id记录框架提供的关联。Agent会话身份独立，参数和返回载荷使用原始键和值。耗时未知保持未知，未采集结束不称为成功。

DSH采集入口包括制作、情报和来源调查；MCP通用包装器记录宿主实际执行参数及结果。模型输入的采集范围是SDK会话可见消息和工具定义，不是供应商HTTP封装。公开模型输出与隐藏推理分别处理；后者不落盘。上下文替换按源序号执行，缺引用时context_complete=false。SDK工具与MCP宿主没有可靠跨边界callId时分别保留，只共享所属Agent关联，不按名称/时间合并。

制作任务页使用ExecutionViewer：可查看Agent绑定输入、已保存输出，各调用可展开输入、输出和身份/时间；支持按执行类型过滤，原始JSON保留复制入口。execution-labels维护通用参数中文释义，production-trace-labels只维护制作展示注释，查看器不依赖业务阶段。中文注释不更名参数、不改变值；新业务或框架接入也能查看未知字段。

2026-11-04 阅读视图：默认以扁平过程流展示公开模型正文和工具调用，每个span仅一行，不展开整棵调用树。模型正文只读取公开文本块，不遍历source/replayState或隐藏推理；长正文可完整展开。行内显示实际参数摘要、状态和耗时，展开工具行优先显示返回内容；SDK工具返回中的JSON文本可按结构阅读，完整结构、原始键值及复制入口仍保留。长指纹只在行内预览缩写，原值不改写。

宿主MCP成功记录默认通过独立开关查看，不按名称或时间与SDK工具去重；宿主及Agent失败仍直接可见，选择MCP类型时能完整查看宿主记录。过程支持中文展示名、工具参数、公开正文搜索，以及类型/异常筛选、批量展开；搜索不命中每轮模型请求中反复携带的旧上下文。调用树保留准确父子关联，筛选时平铺匹配单元，避免重复嵌套。用量、额度、PDF准备和任务配置收在过程之后。轮询追加保留已有行的展开状态，不强制滚动；页面读取和展示不触发模型。

历史记录只展示已保存内容。旧MCP观测UUID-start/end是已确认的配对身份，可以归并；无关联的记录独立呈现，不能推测某次模型请求。截断、未采集、隐藏推理/二进制省略与未知耗时应如实显示。数据库无历史回填，查看页面、读取日志和复制JSON不调用模型。

新增框架先实现输入/输出与生命周期适配，保留框架自己的调用身份，再接相同ObservationSink和查看器。新增业务通过展示词典或外层阶段分组注释；禁止新增按具体业务猜测的通用追踪分支。完整任务恢复仍由所属业务和租约用例处理。

## 全生命周期费用与上下文运行诊断

`/api/production/tasks/{id}/lifecycle-cost`沿准确父子链汇总全部尝试的已上报用量和估算费用，包含摘要、失败及后继返修，保留待审状态。相同标题、同一天或同一论文的另一个重做根任务不自动合并。脚本入口为`scripts/inspect_production_lifecycle.py`，只读且不领取任务。

`context_window_runtime`仍使用通用WorkflowObservation，记录冻结策略、SDK、可执行文件及适配器hash；并非单独的业务trace。累计预算和工具未挂载有固定公开错误分类，原始供应商文本不回显。调用前工具完整性检查失败不调用模型，不能靠模型自由文本判断基础设施是否就绪。故障指纹仅用于同类问题聚合，不构成自动重试授权。
