# 科研新闻图文制作与后台预览

## 2026-11-06 可选PDF题头（ADR-112）

新生成的本地图文包自动尝试截取唯一绑定主论文的PDF首页题头，放在开篇导语区之后、第一个小标题之前；没有明确分节则放在首个正文段后，不插在小标题与首段之间。独立于最多4张研究配图。无模型、无网络，不重新运行MinerU，不从网页补截图。原始连续矩形保留标题、作者及同区域的刊名/DOI等；刊名只在页脚时不为纳入刊名拉长或拼接截图。

宿主以绑定论文题名匹配首页真实文字行，要求有可定位的紧邻作者区；裁切高度不超过宽度50%、不延伸到首页48%以下，网页/公众号显示宽度最多560px（图高最多约280px，手机随正文宽度缩放）。文字匹配不确定、无文本扫描页、旋转页、作者区过长或布局过高直接省略；已知文件读取失败记录failed并省略。不是所有期刊模板都支持；当前保守规则不包含OCR或模型视觉判断。

作者行识别会合并同一基线、相邻且字号接近的文字片段，支持ORCID图标拆开的姓名及上标编号；远隔的日期侧栏不合并为作者。仍按原始PDF的连续矩形裁切，不拼接图片。

ArticlePresentation.paper_header保存ready/skipped/failed、原因、文档与图片SHA、首页矩形和PNG。省略原因可在既有检查记录查看。题头随准确包持久化、批准和导出；人工改稿复用已存题头，不重新裁切，也不改变研究配图索引。旧包不补字段、不重渲染。新生成包采用模板science-reading-v8与题头识别pdf-header-v2；对缺图旧包显式重新排版会派生新包，不沿用旧批准。没有增加题头独立拖拽/手工裁切控件。


## 2026-11-05 准确正文的重点标注

science-reading-v4支持可选emphasis，网页与公众号同步渲染strong，不重写正文。提交格式为`{"source_body_hash":"准确正文SHA256","items":[{"paragraph":2,"quote":"该段内唯一的准确原句"}]}`，可随LayoutRequest或ChannelSubmission提交，仅支持local_html。发行上下文draft.source_body_hash由宿主计算，模型无需计算哈希；段落按非空行从1计数，包含小标题。

宿主拒绝过期正文、标题行、错位/歧义文字及重复重叠；正文中的HTML始终转义。强调方案保存在ArticlePresentation并参与派生包身份和人工批准指纹，旧包没有该字段时不补写。原图继续用after_paragraph关联解释段落，图片alt包含核对过的图注。本轮不扩大图片数量，不新增生成式插图、段落改写或自动发布。是否选对重点、是否遗漏重要限定仍须人工检查，程序只能保证文字与版本一致。

2026-11-04执行语义更新（ADR-089）：工作台“选图”、重试与继续操作直接调用模型并自动推进，
不再单独勾选费用授权或到详情逐段执行。下文早期“只排队、详情显式执行”的交互描述由此覆盖。

## 已落地流程

已审核稿件 → 原渠道包 → 选取绑定论文的完整原图块 → 宿主固定模板 → 新图文包 → 后台手机/桌面预览 → 网页或公众号正文导出。

原稿、审核报告和原包不变。图文制作不排队写作或复审。人工清单直接渲染不调用模型；DSH选图单独排队发行任务并记录真实用量。相同源包、图像清单和模板版本幂等复用；改图注/插图位置/模板则派生新包。正文只有经原有稿件版本流程才能改变。

- 网页：单栏白底、深蓝标题、手机正文17px，首段18px；原图按自然尺寸显示，上限100%。
- 公众号：独立正文片段，全部样式内联，标题单独填写；不使用脚本、外链字体或生成式正文插图。
- 图像：MinerU缓存导出的PNG，不重新解析PDF，不接受任意文件路径或图片URL；最多4图，每图3MB上限。图块定位、PDF指纹、图片指纹、尺寸和原文链接随包留档。
- 文末只列正文主张实际引用的来源及配图相关来源，不把整个检索池当参考文献。
- 导出检查当前选题/任务书/稿件版本及网页、公众号和原文指纹；失效包不可导出。导出记本地回执，不记对外发布。

## 业务契约与入口

`POST /api/production/layout` 接受 `package_id` 和 `figures`。每项：

```json
{"evidence_id":"当前选题绑定的论文证据ID","page":2,"block":8,"after_paragraph":4,"label":"原文 Fig. 1c","caption":"核对过原图与图注的简短说明"}
```

段落编号按定稿非空行从1开始。宿主先校验图源与重复位置，在数据库事务外取图，完成后再次校验当前版本再保存。不得把图块序号当作论文子图标签。

`POST /api/production/export` 接受 `package_id`，可选 `variant: web | wechat`。后台“发行归档 → 有效渠道包 → 包内容”提供网页/公众号切换、390px手机和820px桌面宽度、放大预览、HTML下载。文字包可生成无图阅读版；可点击“排队 DSH 选图”生成发行任务，在任务详情显式执行；只排队不等于付费执行。人工清单接口仍可用。

后台iframe使用空sandbox隔离；保留父页nonce CSP，预览时将片段内联样式转换成带nonce的样式表，导出内容仍保留内联格式。远程图像不加载。历史包缺少presentation字段仍可读取。

## Skill与模型接入的实际边界

新增产品运行时 `skills/publishing/SKILL.md`，纳入newsroom-v6目录与publishing profile，新发行任务可按需读取；历史任务继续使用其冻结技能快照。技能是项目原创，不复制调研库的代码或技能正文。

DSH发行角色新增 `find_paper_figures` 与 `inspect_paper_figures`，通过 `submit_channel_package(figures=...)` 提交选择。模型看到的是真实MCP图像，图注OCR仅用于定位。宿主只接受当前绑定PDF、实际查看过的准确子图及视觉观察记录。页内索引不能作为发布插图。

宿主一次读取已有MinerU缓存建立图页/图块目录，按PDF SHA持久缓存；每任务最多6个不同查询，每次最多3页。不同查询及证据别名命中同页会复用，不重复返回目录。模型先查看带pNbM标签的页内缩略图索引，再按ID取准确子图，每次最多3图、共6图，已发送图片不再发送。索引仅在命中页导出所需子图；宿主制作索引所处理的图数不等于发给模型的图数。无需重解析PDF或消耗正文读取额度。

观察日志只记录图片MIME及大小，不保存base64；任务保存工具次数、供应商输入/缓存/输出token、执行耗时。派生包关联selection_task_id，后台显示真实任务用量，不把DSH选图显示为0 token。图源、租约、预算和版本由宿主校验；图注语义仍须核对，不能把成功提交等同事实全正确。

### Windows DSH图像兼容

本机固定SDK 0.2.1rc2的打包运行时无法加载Sharp原生模块。发行子进程支持显式兼容配置：运行根目录 `dsh-runtime.json` 的 `windows_sharp_native` 指向已安装的 `sharp-win32-x64-0.35.5.node` 绝对路径，旁边须有配套libvips DLL。Cordis插件仅重定向该固定文件名的加载，记录二进制SHA；不改全局PATH、不替换SDK、不自动安装依赖。缺配置使用SDK默认行为，错误配置明确失败。部署其他环境须重新验证，不能假定本机补丁普遍适用。

## 2026-11-06 公众号草稿箱交付（ADR-113）

发行归档的准确图文预览增加“送入公众号草稿箱”。仅当前、独立核验通过且已人工批准的图文包可发送；选择包内图片作封面（上传永久图片素材），或填写目标公众号已有永久图片素材ID。窗口显示目标账号，确认后后台串行上传图片并创建草稿，浏览/预览/查询状态不连接微信。该动作不调用模型，不包含发布、群发或覆盖已有草稿。

### 账号配置与启用

在项目根目录 `.env` 设置 `PHARMA_WECHAT_APP_ID`、`PHARMA_WECHAT_APP_SECRET`，可选 `PHARMA_WECHAT_ACCOUNT_NAME`（界面账号名称）；也可使用启动进程环境，进程已有值优先。运行台启动仅加载这三个公众号白名单变量，模型及其他命令不因读取模型配置而加载公众号凭证。不要把真实密钥放入仓库、URL、聊天或前端。配置只在服务启动边界读取；更改后须在运行任务完成后重启运行台。未配置时保留交付入口并显示原因，不访问微信。账号仍须具有相应素材与草稿接口权限，并在公众号后台配置服务出口IP白名单；显示“已配置”只代表本地配置齐全，不代表账号权限或网络已实测。

普通启动使用既有 `uv run pharma workbench` 入口和原配置。v13升级沿既有迁移流程备份到运行目录 `backups/`，新增 `wechat_deliveries`，不重写历史稿件和批准。回退先停止写入，再恢复升级前完整备份；不能在存在新交付记录时用旧库覆盖，丢失防重记录可能造成重复草稿。

### 内容与失败恢复

- 正文使用准确包已保存的公众号HTML；图片从该HTML提取，必须匹配研究配图或PDF题头的SHA256。拒绝任意路径、外部图片、缺图、损坏和未登记图片。仅替换图片地址，不重新排版、改标题或追加正文。
- 本版采用每张PNG不超过1MB的保守交付限制（应用限制，不宣称微信平台统一上限），超限明确拒绝；不静默压缩或删图。封面取原图时微信可能裁切，具体效果须在草稿箱检查。无图文章可使用已有永久封面素材。
- 请求UUID绑定账号、准确包指纹和封面；同账号同包已有在途、成功或未知结果时复用原记录，换UUID不能绕过防重。素材上传后、建草稿前再次检查批准与版本。
- 30秒网络超时；无自动网络重试。素材准备失败和微信明确拒绝可在窗口重新提交，新请求保留旧失败记录。已创建的素材可能保留在微信侧，首版不做自动删除或跨请求素材缓存。
- 建草稿时超时、HTTP错误、非JSON或缺少草稿ID都记“结果未知”，不自动重发。服务重启将创建中的记录转未知，其他中断记录转失败；不自动恢复网络动作。
- 未知结果先到公众号后台核对。只有确认不存在时，展开“已核对，草稿确实不存在”，填写核对记录并明确解除阻断，随后才能另行交付。原错误与未知回执保留；这是人工声明，不冒充API核验。若草稿已存在，直接在公众号后台处理，保留原阻断。
- 成功保存草稿media_id和 `submitted` 回执，不记 `published`。历史制作清理遇到公众号交付记录时拒绝，防止丢失包身份和防重依据。
