# 阅读评审与阅读品质验收

## 判断与验收

按 newsroom-v63 的共享编辑判断，阅读评审先看成稿的重要认识、材料主次与理解推进，再看句段表达。问题单描述准确文字造成的理解影响，resolution 是影响消除后的阅读效果，修改示例可选且不构成强制方案。作者按问题成因选择删减、概括、解释或重组；局部提交不限制必要的编辑范围。

复核沿稳定问题 ID 检查当前成稿的实际效果与改动影响，允许纠正无效建议，不以执行建议或增加解释作为关闭依据。结论须回应盲读中的实质障碍。协议与返修额度不变，历史冻结任务不改写；离线契约检查不认证语义质量。

## 界面名称与返修语义

制作链显示为：主编选题→初稿撰写→阅读评审→事实核验→图文编排→人工定稿。reading-review在界面叫“阅读评审”，仍独立评审阅读推进和自然度；fact-check显示“事实核验”。新任务使用 ADR-115 的阶段标识，历史制作数据需在切换前清理。

作者任务输入已有准确稿件时显示“稿件返修”，没有稿件时显示“初稿撰写”。返修继承当前稿件、研究底稿、证据与问题单，按具体问题修订，必要时补查；不是重新立项或强制从头研究。每次仍启动新模型会话，不承诺继承前轮对话。物理工作目录按角色共用，不能把目录保留称为每篇独立会话工作区；可靠交接依赖版本化产物和绑定任务上下文。

## 流程与职责

主编选题→作者研究与写作→阅读评审→独立事实核验→图文制作→人工定稿。阅读评审和事实核验复用reviewer角色配置，但业务阶段、工具、报告与通过条件分别记录。阅读通过不认证事实，不等于人工定稿或对外发送。

新根任务冻结reader_policy并沿后继传递。旧无策略的链不补跑，继续/重试保留冻结策略。新稿记录阅读策略；重做使用当前新链。协作编辑的新稿在启用新流程时重新进入阅读评审。事实修订后的每个新稿保守重走阅读复核，不按修改字符比例推断是否仍然合格。

## 两项评审与分步读取

reading-review技能包含新闻吸引力/阅读推进、中文表达自然度两项方法。前者检查新闻承诺、解释顺序、选材主次、段落关系与收束；后者检查翻译句法、英文结构迁移、论文解释腔、审计口吻与重复模板。AI味是诊断线索，不是来源判定或禁词规则。

对包含多个解释任务的正文，阅读推进评审检查跳读时能否找到关键结果、相关解释与依据，以及小标题能否准确预示本节内容、所辖段落是否围绕本节主题展开。内容有依据、与全文主线相关，不代表当前位置合理。分节缺失、标题含混或标题与内容不匹配，确实造成内容范围误判、定位或理解困难，或明显打断阅读推进时，可以根据成稿的代表文字列必改，说明应恢复的内容关系，不指定唯一改法。标题措辞的个人偏好不阻断；连贯易读的短稿可以没有小标题，不按数量判定。

新排队的node-context-v2阅读评审采用三个常规调用：get_reader_review_context交付完整标题、正文、准确版本和全部冻结必读规范及案例；record_reader_observation原子保存第一次阅读理解、阅读理由与第一处障碍，再返回任务书、前轮阅读报告及作者回应；submit_reader_review提交两项结论。首次观察同内容重交幂等，不允许覆盖，缺少必读资源或首次观察时不能开放任务书，未核对任务书不能提交报告。合并工作集沿用通用上下文清单与回执，读取记录仅表示宿主处理过资源。

上下文缺失时可重复get_reader_review_context取得完整原稿、冻结材料及本任务已保存观察；已有观察时record_reader_observation省略result可恢复任务书。三次是正常路径，恢复和按需读取历史报告可以增加调用。阅读评审沿用Harness常规压缩，返修专用活动窗口仍只用于作者返修；摘要后的准确内容从冻结工作集恢复。评审材料、判断标准、准确版本校验和返修额度保持原契约。合并后的真实模型质量与费用仍需同稿对照验证。

历史任务保留冻结工具与提示词，get_reader_draft仍只给当前标题、正文和版本身份，save_reader_observation后由get_reader_brief开放任务书。新旧入口均隔离作者底稿、自审与事实通过意见，不开放证据检索、PDF、改稿或事实提交工具。

作者底稿可核对，正文负责阅读。不能因后台有解释而替正文补义，也不能因每个术语最终能解释就判为可发表。重要原则：先判断细节是否应当保留，再决定补解释；不能把所有阅读问题都转成增加实验细节。

首次观察保存后，复核角度和立项理由中的已证实新闻信号。若影响阅读理由的刊会状态、机构行动或具体进展被泛称或次要细节掩盖，可列入阅读推进必改。常规出处不因此成为首屏要求，允许从更有解释力的实际发现切入。证据归属与发表状态是否准确仍由事实核验判断。见 [ADR-104](architecture-decisions.md#adr-104把已核实的新闻信号带进标题与导语)。

## 问题与结论

ReaderIssue包含稳定ID、dimension、required/suggestion、当前文字anchors、problem、reader_impact、resolution（可验证的阅读效果，不要求修改方案）和可选局部示例。跨段缺陷允许多个短锚点，同原因合并，不机械给每段报错。

required须说明具体理解或重大持续表达缺陷；suggestion是已经能理解但可改进。单个“论文作者”、被动句、长句、术语或数字不自动退稿。必要归属、科学限定与比较条件必须保留。持续把全文写成论文目录或审计说明，可以构成独立阅读必改，不受事实核验“style只能suggestion”的限制。

新提交ReaderReviewResult只有ready/changes_requested，两项均须completed。ready必须没有required；changes_requested必须有required。各维度按是否有本维度required显示通过或要求返修，completed不作为通过结论。旧ReaderReviewSubmission仅为保留历史rebrief_needed的读取能力，不能再提交该结论。工具或读取失败不能伪装为已完成/空问题通过，应报告实际阻碍。

报告绑定准确draft_id/hash、brief_version、目标读者资源hash及技能快照hash，保存在review拥有的reader_reviews表。程序校验定位、完整性与结论一致性，不认证意见的语义质量。

## 修订、收敛与版本

新任务全流程自动作者返修默认5次，可在启动/重做中设为1–10次；阅读评审与事实核验共用总额，通过就提前结束。旧未声明总额的任务保留原冻结上限。作者在resolved_issue_ids回应必改，并在reader_responses逐项记录revised/retained及理由；解释性记录不写入正文。是否真正解决由新阅读报告依据当前文本和原reader_impact独立验证，并按原ID在summary记录关闭或保留依据。复核沿稳定ID关闭或保留原必改，只检查原问题及实际改动带来的明显缺陷，不重新发起偏好竞赛。建议未采纳不阻断。

仍有必改或需改角度时，报告成功保存，任务为succeeded，但选题deferred、工作台显示要求返修 · 自动修订已停止；这不是技术失败，也不是事实审核通过。恢复须明确新处理动作，不无限自排模型。

按照实际排队的作者修订意图统一计数；作者失败后的继续/重试、单纯通过和独立复议报告不重复扣次数。事实修订后的新稿失去旧稿阅读许可，必须取得新版本阅读ready；事实核验和制包均检查绑定。带阅读策略的渠道包在导出/人工定稿的有效性检查中复核真实阅读报告。原事实审核规则不放宽。

SQLite v12只新增阅读报告表及索引，升级前沿既有机制备份；旧审核、稿件和制作历史不回填。回滚停止新写入并恢复备份，不倒退迁移编号，不用副本提交冒充生产结果。

## 验证与真实回归

离线验证覆盖分步隔离、MCP白名单、定位错误、未完成拒绝、准确版本、旧链不补跑、有限返修、额度停止及迁移备份/重复升级。前端用文本转义显示锚点、影响、解决条件及首次观察，阅读/事实结论明确区分。

本次用户授权对同一AutoDNA论文在隔离数据库执行真实回归，原PDF hash不变，不执行图文模型、人工定稿或对外发布。第一组检查原已通过稿件能否被新阅读评审识别；后续从新主编选题重新写作，逐轮保存稿件、阅读报告、事实报告、模型用量和生产历史指纹。技术失败和规则版本逐项保留，不把工具成功、模型ready或单题材改善当作稳定质量证明。

完整本地记录：data/reports/reader-quality-20261105。当前同论文回归不是公众盲读或跨题材泛化验收，后续校准集应包括应当通过的稿件及必须保留复杂条件的反例。

新技能newsroom-v52的作者返修使用get_revision_context/submit_draft_revision：仍是draft-writing阶段和同一返修额度，按问题成因确定必要改动，宿主合成完整新版本。未关闭问题、全文和准确引用保持可见，历史报告按需读取；初稿研究方法不再每轮必读。局部提交不会继承旧稿阅读或事实通过资格。详见ADR-109。


## 按需读取历史阅读报告

带revision-window-v1且冻结read_reader_review的任务保留完整盲读成稿，保存首次观察后才返回任务书、最近一轮阅读报告和作者回应。更早报告仅给准确报告/稿件/hash、结论、打开及关闭ID；通过read_reader_review(report_id)按需展开一个冻结报告。不能读取其他任务的报告，不能绕过首次盲读。独立复核及逐项关闭规则不变，不因省上下文而跳过整体阅读；历史工具清单缺此入口的任务保留旧投影。
