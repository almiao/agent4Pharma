# AI × Biology/Pharma：主题范围与筛选迁移

日期：2026-10-29（Asia/Shanghai）。用户已确认扩大范围，目标覆盖 BioTender 的研究与产业主题；以本文件和 ADR-015 取代 ADR-009 的窄范围约束。

**定位：持续追踪 AI 与生命科学、药物研发及相关医学转化的研究、模型、工具、数据和产业变化，为重点内容生产提供候选。** Agent、深度学习、生成模型、基础模型（含非语言模型）与强化学习等可进入范围；仅使用传统机器学习的研究不纳入；不再要求实际参与制药才相关。

2026-11-01 用户收紧方法边界：仅使用传统机器学习的研究不纳入，是否提出原创算法不作为主题门槛。本次更新共用标准及随包默认正文，通过新版本发布作用于未来任务，不改写历史批次。现行来源召回仍未全面验证，不能由范围确认推断来源全覆盖。

## 1. 参考依据与覆盖方式

2026-10-29 实读 BioTender 的 [Agent 入口](https://www.biotender.online/llms.txt)和[官网](https://www.biotender.online/)。入口声明其覆盖蛋白设计、结构预测、虚拟细胞、AI 制药、生物基础模型、科研智能体、产业和评测；官网还有医学转化、组学、数据、实验室及生物安全等内容。

下表是我们的统一分类建议，不声称它就是对方的全部分类。来源于用户所贴两篇文章的“完全自动化”和数量宣传不作为实现质量证据。网站未来新增栏目不自动修改本项目范围，由来源维护提出版本化变更。

| 主题 | 收录内容 | 进入精筛的例子 |
|---|---|---|
| 蛋白结构、动力学与设计 | 折叠、复合物、构象、相互作用、酶、功能蛋白、全原子建模 | 结构预测模型、扩散蛋白设计、酶功能验证；不要求药物关联 |
| 抗体、肽与生物药 | 抗体、纳米抗体、结合蛋白、环肽及细胞/基因疗法设计 | 抗体生成、亲和力与可开发性、多目标设计 |
| 小分子与药物研发 | 分子生成、性质预测、靶点、筛选、ADMET、合成、递送与研发流程 | 图神经网络、生成模型等的实际药物任务 |
| 生物基础模型 | 蛋白、分子、DNA/RNA、细胞、跨模态与世界模型 | 非语言基础模型直接属于正常主题，不再统一降为待审 |
| 虚拟细胞与系统生物学 | 扰动响应、细胞状态/命运、机制与跨尺度模拟 | 虚拟细胞、细胞群体预测、治疗假说 |
| 单细胞、空间组学与多组学 | 转录组、蛋白组、代谢组、组学融合与生信方法 | AI 表征、跨组学推断、空间结构分析 |
| 基因组、RNA 与合成生物学 | 调控、基因编辑、序列设计、合成基因电路、生物工程 | 基因组模型、RNA 设计、AI 酶工程与生物制造 |
| 科研 Agent 与工具生态 | 科研智能体、Skills、MCP、生信工具、文献与研究流程 | 生命科学任务中的工具调用、证据整合与评测 |
| AI 实验室与自动实验 | 自主实验室、机器人、实验规划、主动学习、设计—实验反馈 | 模型与湿实验闭环；纯仪器升级须有直接使能关系 |
| 数据、Benchmark 与方法评测 | 数据集、实验反馈数据、验证集、复现报告、泄漏与泛化分析 | 生物任务基准、跨细胞系泛化、结构模型比较 |
| 医学与临床转化 | AI 药物管线、疫苗、诊疗、医学模型、影像/病理、临床试验 | 生物医学研究或真实临床转化；不再要求一定指向制药 |
| 产业、治理与研究基础设施 | 公司/实验室、合作、融资、产品、许可、监管、生物安全与算力 | 能明确关联上述主题的事件，而非所有科技或医疗新闻 |

同一资料可以有多个主题。材料类型（论文、代码、模型卡、公告、访谈、数据、评测）单独标注，不混入主题标签。农业、环境与工业生物学中的 AI 生物研究可按合成生物学等主题纳入，不限于人类治疗。

## 2. 范围相关与值得报道分别判断

纳入主题至少有一个可说明的 AI—生物/医学联系：方法实际参与任务、研究 AI 在该任务中的能力/局限，或事件直接改变相关研究与应用条件。仅使用传统机器学习的研究不纳入；使用现成深度学习等方法不因算法非原创而排除；“AI”或“基础模型”字样也不是自动推荐理由。

- 正例：无药物任务的蛋白生成模型；深度学习单细胞分析；AI 辅助酶设计；虚拟细胞数据集；医学模型可靠性评测。
- 反例：只用 AI 润色的普通生物论文；没有 AI/相关基础设施联系的公司融资；没有生物医学应用证据的通用聊天模型发布；纯医疗行政系统采购。
- 信息不全：只有“AI 生物平台”标题或宣传，无法判断实际任务时，标待补证，不凭缺词排除或推荐。
- 生物数据库、仪器或实验数据本身未必使用 AI；若明确使能相关模型、评测或闭环，则可以作为资源/产业内容进入判断。

蛋白结构预测等成熟领域仍需看新信息和编辑价值，避免把宽范围变成无差别论文搬运。证据成熟度（计算、体外、动物、临床等）是比较维度，不是“一律只有临床才有价值”。

## 3. 发现策略

从单一“Agent/大模型 AND 制药”改为版本化主题分支的并集：每个分支包含领域任务、方法概念、代表项目锚点、排除语境和适用来源。生物基础模型与蛋白结构项目可以直接触发补读，不强求 drug 词。

论文平台按来源语法生成分支查询，保存查询版本、窗口和截断状态；已采集资料统一交本地 Decider 判别，关键词只编译查询。综合媒体需判断正文实际关系。裸 agent 仍可能是试剂，不能单词放行。缺摘要、网络/模型失败不等于范围外。

## 5. 与内容生产的关系

范围决定什么可以进入候选，不规定每日篇数和主题配额。主编按读者价值与制作容量选择论文深解、专题比较、产业观察或工具/评测解读；深度解读仍是已确认的主要产出。日报可作为后续内容类型，不因参考文章自动成为必做产品。
