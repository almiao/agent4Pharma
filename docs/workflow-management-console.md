# 运行台当前状态与迁移边界

## 数据契约变更后的重载

工作台是常驻 Python 进程，不会随源码修改自动更新已导入的数据契约。独立 CLI/MCP
子进程会读取磁盘上的新代码；因此新增持久化字段后，旧工作台可能无法读取新子进程写入的记录，
并在制作或产物列表报 `Extra inputs are not permitted`。前端构建成功不代表后端契约已更新。

涉及持久化契约的改动，应在队列空闲时重载工作台，并验证制作汇总、产物目录、论文状态和
人工审核四个只读接口，再执行写入新格式的任务。存在运行中任务时先等待结束，不能直接终止；
存在显式自动队列时须考虑启动恢复会继续调用模型。重载后刷新页面获取新会话令牌。
排查此类错误时比较运行中接口与当前代码对同一库的只读结果，不以放宽字段校验或删除记录恢复列表。

## 精选失败恢复（2026-11-05，ADR-099）

精选失败时，错误卡片直接提供“重试本轮比较（调用模型）”。点击复用准确运行已冻结的输入、前十和本地结果，显式重置该运行比较重试预算后执行；不重新采集或采用新提示词。运行中按钮加载，失败显示具体固定校验原因；清单未形成时显示“未形成”，不将其冒充真实零入选。GET、刷新和历史浏览不触发执行。

## 当日日常跑批（2026-11-05，ADR-097）

运行总览和情报节点共用工作台顶栏。情报节点在顶栏选择查看的批次。顶栏的“运行今日批次（调用模型）”执行服务端北京时间当天的来源采集、本地预选、价值排序和论文精选，包含真实模型调用；运行中按钮禁用，可离开页面后返回查看。结果显示实际归档资料数、建议下载数及准确批次入口。部分来源失败显示部分完成，技术失败保留诊断，不冒充排除。重复请求复用活跃尝试，完成后可显式新跑一轮；历史保留。后台重启将中断尝试标为失败，需要用户显式重试。GET及刷新不启动工作，不自动启动依赖服务、下载PDF或采编制作。


## 当前采编流程（2026-11-04，ADR-092）

主编选题（摘要与必要背景）→作者研究与写作→编辑核验→图文制作→人工定稿。
不再先运行独立论文理解或背景阶段。作者在同一写作任务内先保存基于选题的研究底稿：
中心问题的回答、论文事实与出处、必要背景、未决问题及省略/限定/阻断处置。保存后继续写作，
不新排研究Agent、不等待人工确认；编辑与返工复用底稿。主编与作者可有界搜索背景。
继续/重试保留已保存底稿，仍从新的模型会话执行；未提交正文不能冒充保存点。
本条覆盖下文旧理解链与作者无搜索权限的历史说明；具体契约见[新闻技能](newsroom-skills.md)。


2026-11-02 更新（ADR-067）：正式导航改为七节点，摘要比较与人工推荐/下载合为“论文精选”。人工明确推荐并校验主文后直接进入稿件制作，不再执行获取后的推荐复筛；后续问题由对应节点处理。旧八节点与全文终判描述仅对应历史流程，历史评估不改写。

更新：2026-11-02。本文只描述当前实现和入口；逐功能实施范围见[迁移矩阵](console-migration-matrix.md)；逐轮设计和验证归档已清理。

## 制作任务（2026-11-03，ADR-071）

稿件制作按论文展示立项前任务、成功阶段保存点与完整父子链。已立项选题可检索原论文标题，并查看研究阶段。当前阶段支持暂停、停止、继续和重试；恢复只排队冻结阶段后继，仍需费用授权执行。移除同时仅一篇active选题的准入限制，实际后台保持有限并发。保存点是已提交阶段产物，非模型会话中途无损续接；历史阻断不自动重跑。

## 两个入口

运行 `uv run pharma workbench --port 8765`。源码位于 `frontend/`，Vite 构建到 Python 包内 `static/live-console`；启动及 CSP 约束见[前端说明](../frontend/README.md)。

| 入口 | 数据与用途 |
|---|---|
| `/console`（或 `/`）、`view=workspace` | 新版正式工作台，读取真实记录；制作/审稿/交付全部选题，情报按批次 |
| 旧 `view=legacy`、五工序书签 | 仅转换为新工作台准确对象/记录地址；不再渲染旧后台 |

| `/settings` | React公共规范与节点提示词配置；共用正式工作台导航 |

正式工序使用 `/console?stage=intel`、`editorial`、`content`、`review`、`publishing`。旧独立工序路径及来源维护网页已下线；离线调查用例与历史数据保留。

## 正式后台已有能力

- 按明确批次/选题身份查看来源资料、初筛、情报任务、候选、制作任务、稿件、核验报告和渠道包；指标与集合必须使用同一口径。
- 人工 PDF 连接、启动、匹配关联、失败重试及暂停恢复，沿用服务端清单/预算限制；下载不隐含模型执行授权。
- 立项排队、准确阶段暂停/停止/继续/重试与独立复议；网络/模型执行按本次授权和限额执行。
- 稿件编辑建议、差异预览、接受修改和历史恢复；生成新版本后由人工直接确认定稿，旧包的批准不能用于新稿导出。
- 图文包预览与本地 HTML/Markdown 导出、回执；目前没有真实对外发布能力。
- 已有程序步骤观测、部分 DSH 流事件与模型结果/用量记录；完整会话、调用关联、实时过程仍需补齐。

详细业务条件由[筛选流程](paper-selection-pipeline.md)、[生产契约](editorial-production-contracts.md)、[稿件编辑](article-editing.md)、[图文制作](publishing-layout.md)及实际服务端用例定义。正式 API 已新增 `/api/production/human-review` 和 `/api/production/approve-package`；人工批准不能替代独立核验，所有渠道包导出均须批准。见 ADR-055。

## 新交互 MVP

批次层八节点：来源采集 → 初筛 → 本地摘要排序 → 商业整体复核 → 全文准备与终判 → 采编制作 → 人工审稿与定稿 → 发布。节点数字是当前停留文章数，箭头是累计交接；清单可切换当前/历史。

样例含 14 篇来源资料：初筛通过 12、排除 1、技术失败 1；冻结前 10 共同比较，摘要选出 5；2 篇已有虚构全文，3 篇人工下载待办；1 篇正式推荐进入制作。此篇已完成制作、默认等待人工审稿，因此制作当前停留为零。整轮输入/输出与逐篇结果关联，不伪造独立单篇比较。

单篇执行可从任务下钻至公开响应、工具参数/返回、提交拒绝、返工、产物及版本交接。稿件支持桌面/手机预览、编辑草稿恢复、另存版本、段落比较、版本意见、技能/工具草稿和本地任务队列。人工审稿后直接进入发布；修订仍留在审稿业务阶段。发布成功/失败/重试均为模拟。

常用深链接：

- 批次审稿清单：`/console?view=observe&screen=batch&stage=human`。
- 单篇审稿：`/console?view=observe&mode=editorial&task=human`。
- 单篇发布：`/console?view=observe&mode=release&task=publish`。

版本、意见和本地发布状态存于 localStorage `a4p-editorial-demo-v1`。样例不读取生产接口，不执行模型、下载或外部发布。其人工批准和工具勾选不能作为正式权限规则；图文集合为空，预览只是正文和固定排版，不是完整渠道效果验收。

## 验证与切换

离线契约测试覆盖集合口径、版本身份、拒绝不产稿、独立返工、批准与版本隔离、发布重试、当前/历史分离。浏览器验证列表、下钻、返回和刷新恢复。真实模型质量、真实来源与对外发布需独立授权及验证。

迁移期间仍以服务端记录为正式真相，保留来源/设置页、CLI/MCP 与旧数据读取。只有在矩阵对应功能完成迁移及验证后，才退出旧正式页面。禁止接口失败时自动展示 fixture 成功状态。

## 第一批真实迁移的边界

正式新界面源码为 real-workspace.jsx、real-workspace-model.js、real-task-process.jsx。前五节点暂嵌入原情报组件并选择相应页签，完整新版过程布局仍在迁移中；来源/设置保持专用页。人工审稿直接使用真实渠道包、核验报告和冻结证据；稿件编辑复用已有 DSH 修改建议与接受流程，没有把样例任意工具配置或本地意见迁入正式状态。

`/api/production/tasks/{id}/observations?after=<seq>` 每页最多 50 条，返回 next_cursor/has_more。界面五秒轮询读取追加观测，缺失事件保持未记录；完整逐轮模型消息尚未全部采集。旧运行总览依旧读取真实数据，但导出同样受人工批准限制。没有外部发布请求。

schema v11 在启动边界自动升级并产生 data/backups/discovery-pre-v11-*.sqlite3；旧包不自动批准。失败升级自动回滚，人工需要回滚库时停止所有进程，再从 pre-v11 备份恢复并使用对应版本代码，禁止在写入期间覆盖数据库。
## 全局服务与任务状态（2026-11-02）

正式工作台和原运行台右上角均提供“服务与任务”入口，抽屉分为依赖服务、业务后台任务和 PDF 解析任务。
依赖通过 `/api/dependencies` 只读检查：运行台接口、本地 MinerU 引擎、已启用的 Decider 健康接口，
采编模型仅显示凭证是否配置，不发送付费健康请求。检查缓存20秒、页面15秒轮询，失败或超时显示未知及最后检查时间；
浏览页面不自动启动、重启、重试服务。MinerU 检查最多6秒，Decider 最多2秒，不输出原始日志、凭证或连接地址。

后台任务沿用 `/api/background-activity` 的业务范围，运行、排队、暂停、待确认与历史失败分别统计，详情链接保留准确任务身份。
解析任务在打开抽屉时按需读取 `/api/dependencies/mineru-tasks`，最近20条显示文档短身份、解析档位、页码和状态，并标明总数。
解析队列长度不等同于正在解析数量；历史失败不表示有任务在运行。未登记的外部进程不在业务任务统计内。


## 2026-11-02 旧运行台退役（ADR-069）

此项覆盖本文此前关于旧正式运行台仍可访问的描述。`live-main.jsx` 仅装配新工作台、专用提示词页和显式样例页；旧 LiveConsole、旧运行总览/侧栏/集合抽屉装配已删除，无旧页回退分支。正常导航不再出现“原运行台”。

| 原有能力 | 新页面入口 |
|---|---|
| 未立项任务、失败任务及冻结输入/产物/过程 | 稿件制作中的准确任务页；不要求先有选题身份 |
| 正式候选选择、排队立项 | 稿件制作 → 候选立项 |
| 任务书与编辑决定只读、准确阶段暂停/停止/继续/重试 | 稿件制作 → 历史记录与准确任务；不设人工补证或选题级管理（ADR-076、ADR-077） |
| 当前/历史稿件、核验报告、独立复议 | 稿件制作/审稿定稿 → 业务记录与任务，选择对应记录类别 |
| 当前/失效/已导出渠道包、回执、排版和编辑 | 稿件交付 → 业务记录与任务；审稿/交付详情继续复用真实预览和编辑器 |
| 论文模型任务、PDF 下载、历史评估 | 论文精选 → 处理记录，不重新引入获取主文后的推荐复筛 |
| 来源和提示词版本配置 | `/sources`、`/settings` 专用页面，返回和侧栏进入新七节点 |

`console_routes.js` 为唯一前端地址转换契约。旧五工序路径与 `stage`/`view=legacy` 书签只用于定位新工作台；保留 object/task、story、batch、产物版本、空 ids、collection、状态和重复 source 筛选，不按标题或最近记录猜身份。源路径由 HTTP 提供同一 React 入口，不再提供旧页面。生产记录按需加载产物摘要和候选，不读取大 RSS 池；普通制作详情仍只读取制作与人审索引。

本次复用业务对象组件、公开用例和既有服务端权限/费用/版本控制，不复制旧状态机，不删除任务、产物、历史结果或 CLI/MCP。未实现的完整持久批注、外部渠道发布、全量统一指标和逐轮模型采集仍为原迁移缺口，不因旧页面退役被视为已完成。

验证：492项Python测试、56项前端/样例测试、Ruff/格式/架构检查和生产构建通过。浏览器核对截图中旧失败任务地址被转换为新准确任务页、主编三条任务、候选立项及核验记录归属；未执行真实模型或修改业务结果。本机下载集成测试显式关闭环境代理，避免回环请求被代理为502；旧入口别名采用与新入口一致的CSP nonce策略。

## 2026-11-03 论文精选层级与轻量查询（ADR-070）

论文精选默认只有“论文清单 / 入选依据”一层页签；移除“当前工作 / 处理记录”顶层切换、常驻技术运行ID选择器，以及“推荐清单 / PDF下载记录”嵌套页签。人工推荐、PDF关联和失败原因/准确任务链接继续在论文旁呈现。历史运行、准确运行身份和PDF下载历史在“历史与诊断”侧栏按需查看；历史评估入口仍保留，不参与当前推荐复筛。

默认页面仅请求 `/api/paper-selections?batch=<id>&run=<optional>`，不加载采集文章、粗筛池、历史全池、全部制作快照或候选池。查询返回运行目录及一个准确运行的下载清单与同轮比较成员，完整总数和冻结比较结论保留；显式run不属于batch时拒绝，不回退其他运行。目录只缓存不可变修订文件的元数据，文件路径/修改时间/大小变化使缓存失效，不缓存可变领域对象。运行尚在筛选时明确清单未形成，不把缺少比较结果视作零篇推荐。

PDF历史在侧栏打开时请求 `/api/paper-selections/downloads?batch=<id>`，失败显示未知，不替换为成功空结果。运行已完成且无处理中论文时不再定时读取；有活动时由父页面每15秒读取轻量接口，子列表不重复轮询，暂停不自动继续。浏览、切页和读取历史均不调用模型、不重试下载或修改业务记录。

只读投影改为条目浅复制后覆盖顶层展示状态，冻结请求/策略/正文仅读取；筛选统计仍使用完整池，机构匹配和行序列化只处理需显示的成员。实际同批查询由约17.1MB缩至36.6KB，首次目录读取约0.57秒、复用目录约0.11秒（直接测应用查询，不含网络/浏览器绘制）；当前5篇下载候选和10篇比较输入与旧投影逐项身份及统计一致。新查询的实测基线不代表所有历史批次的耗时保证。

验证：495项Python测试、60项前端/样例测试、Ruff/格式/架构及生产构建通过。实际组件静态渲染确认默认仅两个页签、无嵌套推荐清单/常驻运行选择器、准确失败任务链接保留；本轮无浏览器实机点击验证。8894已重载，React入口返回200，未授权轻量接口返回403；未调用模型、触发下载或改写历史业务结果。


## 2026-11-03 论文精选合并列表

论文精选的搜索栏支持按比较结论筛选，可与标题、期刊或 DOI 搜索叠加。排序可切换为本地排名（靠前优先）或期刊名称，缺少对应字段的论文排在末尾。列表显示命中数，重置可恢复原有顺序并清除筛选。控件作用于当前批次所选运行。
