# 管理后台前端

2026-10-31：用户确认 React + Ant Design 运行台与五工序工作区作为唯一后台基线。源码不再放在 design-preview；本目录包含正式后台和使用 view=observe 显式进入的新交互 MVP；样例尚未迁移真实接口。

## 构建与运行

需要满足锁定 Vite 引擎要求的 Node 版本（20.19+ 或 22.12+，建议 Node 24），并让 node 与 npm 来自同一安装。可在仓库根目录执行 `powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1 -BuildFrontend`；或在本目录执行：

```powershell
npm ci --include=optional
npm run build
```

安装失败时检查 Node 与 npm 是否调用同一版 Node。一键安装脚本会统一通过当前 Node 执行 npm CLI。

回到项目根目录运行 `uv run pharma workbench --port 8765`，打开 `/console` 或 `/`。需要边改边构建时执行 `npm run watch` 后刷新 Python 服务页面；不再启动独立演示服务器。

构建产物输出到 `src/agent4pharma/entrypoints/web/static/live-console`，随 Python 包分发。生产服务不需要 Node。提交源码变化时同步重建产物，勿单独修改压缩文件。

## 责任与导航

- daily-batch-control.jsx：正式概览与情报节点的当日跑批、状态轮询和准确结果入口；POST即请求真实采集与模型执行，加载期间禁用，失败/部分完成明确呈现。
- background-activity.jsx：首页全局后台任务、实时步骤、进度与状态过滤；只读轮询，不执行任务。
- manual-pdf-import.jsx：多下载目录查询、匹配、歧义选择及推荐确认；不上传任意路径，只有明确确认推荐并启动采编才授权模型。
- live-main.jsx：唯一新工作台/配置/显式样例装配、同源 API；旧 LiveConsole 已退役。
- prompt-workspace.jsx：公共规范与节点提示词分组，规范正文、阶段用途、新草稿、对比及发布；目标读者入口为/settings?node=audience。
- real-workspace.jsx、production-records.jsx：七节点、准确任务及候选/版本/历史业务记录入口；复用 StageWorkspace 对象能力。
- console_routes.js（随包静态模块）：唯一地址转换契约，旧书签保留身份和筛选范围后进入新页面。
- stage-workspace.jsx：五工序对象列表、筛选、详情、准确版本和业务命令。
- paper-download-control.jsx：常驻浏览器连接、单篇 PDF 人工启动和进度／保存；等待授权不扣额，备用地址仅作故障兜底。所有权限、清单和预算由后端复核，不接受自由网址／路径。
- workspace-model.js：既有业务投影到页签的映射；不拥有任务状态或领域规则。
- production-limits.jsx：新建任务额度字段；阶段重试由服务端复用冻结配置。
- manual-article-editor.jsx：准确图文的标题、正文、图注和原图段落位置表单；显式保存为待人工定稿版本，取消确认、错误保留输入和关键表述关联校验。article-editor.jsx装配“手动编辑”，复用版本切换、撤销和直接人工定稿。
- live.css / workspace.css：沿用暖白墨绿的布局与响应式规则。
- 静态业务投影仍由 Python 包内 flow_projection / node_metrics / run_scope 提供；链接输出统一指向当前运行台，不再访问旧工序页面。

任务书由自动选题节点生成；模型执行必须明确授权。排队、实际执行、版本通过和对外发布仍是不同业务动作，前端不提供任意改状态或人工审核通过。

## CSP 与验证

服务为当前页生成样式 nonce，Ant Design 使用相同 nonce。构建中对 rc-util 临时测量、portal 滚动锁及 input 文本框测量做三处固定适配，不开放 unsafe-inline 或 unsafe-eval；上游代码变化时适配不匹配会构建失败，要求重新检查。

`uv run pytest -q` 包含前端投影契约。实际浏览器检查及隔离 SQLite 表单检查位于忽略目录 data/reports/ai-workbench；不使用真实模型。生产库仅浏览，写操作在隔离库验证。UI/样本验证不代表模型质量验证。

旧后台 A/B/C、旧选题演示、旧流程画布与旧五工序模板/脚本已删除。来源与设置均已迁入React并共用正式导航；来源维护网页已下线。新版迁移范围见[逐功能矩阵](../docs/console-migration-matrix.md)，样例操作与真实能力边界见[运行台说明](../docs/workflow-management-console.md)。

## 交互性能（2026-11-05）

普通点击以200 ms可见响应为目标，接口完成与后台任务完成分别测量。
`workbench-api.js`只合并在途GET，POST前后隔离读取；工作区已读快照有界保存，修改后清空并重验。
任务阅读切换不重复取详情，执行日志独立分页；服务健康/解析列表按对应页签查询。
排序加载单个完整运行与历史目录，不再读取采集全池。来源、提示词与显式样例分块加载。
通用动效60–120 ms，并尊重系统减少动态效果偏好。
服务端对哈希资源长期缓存、协商gzip，HTML/API仍不缓存。详见[性能说明](../docs/ui-performance.md)。
