# 科研新闻业务技能

## 当前角色与阶段

技能包版本见 `catalog.json`，角色与阶段沿用 ADR-115。reviewer 同时装配 reading-review 和 fact-check，两者分别绑定任务。evidence-check 是跨角色取证方法。

这是产品运行时的技能库，不是开发助手的 `.agents/skills`。入口见 [workflow.md](workflow.md)。
当前链按主编选题、作者研究与写作、阅读评审、事实核验、图文制作交接。理解与背景调查是阶段内按需方法，作者底稿保存后在同一任务继续写作。外部材料的出处和转引关系由背景调查按需核对。
draft-writing 保留 Great Writer 的内部连续流程，不能把其 core 文件分别排成 Agent 任务。

- `skills/`：方法、适用条件及局部恢复规则。
- `standards/`：目标读者、证据和中文编辑规范；news-signals 集中维护共同编辑判断与新闻信号，各角色引用，不重复制定验收标准。

newsroom-v18：用户目标读者demo作为统一规范；主编reader只细化本篇解释重点。三份规范在设置页共同编辑、
保存新草稿与发布，新制作链冻结当前版本，后继继承公共规范；各阶段读取对应规范。价值排序/论文精选消费
冻结受众，主题初筛不增加受众门槛。
- `contracts/`：五个交接产物的内容约定，不是声称已存在的数据库/API 字段。
- `roles/`：主编、写作的责任与裁决边界。
- `catalog.json`：可发现目录、发布版本、可读取资源白名单及执行入口配置。
- `provenance.json`、`licenses/`：上游提交、逐文件改编关系与许可。

允许宿主通过明确的目录加载资源；资源本身不授予搜索、文件、模型、发布权限。
修改方法应进入所属 Skill；新增科学证据规则进入 standards；新增渠道不进入写作核心。
发布前检查内部链接、目录覆盖、快照读取、构建包资源和旧任务兼容。更新本地上游仓库不会自动更新此库。

新增 publishing 技能用于定稿后原图编排与双渠道呈现；独立于前五个采编阶段，新发行角色加载该profile。

newsroom-v7：主编以reader_hook/share_reason记录并判断必需的传播性；不成立不立项。写作结果先行、保留具体小标题，终审验证聚焦兑现。方法参考 https://github.com/wdl339/xinzhiyuan.skill ，本次规则为原创，不复制其技能正文。

newsroom-v8选题技能以用户提供v2为底稿；显式editorial_policy随技能包冻结，版本升级保留传播门槛。报道类型和篇幅在acceptance内约定。

newsroom-v9写作资源分工：standards/chinese-news-style负责语言品质；modes/science-news负责报道类型与信息顺序；core/structure-design负责本篇内容取舍、小标题和证据位置；起草动作并入feature-writing/SKILL，由其负责输入、起草、调用与恢复。事实规则归scientific-evidence，自审、精修和提交检查沿用各自用途，不把方法文件当新增业务节点。

newsroom-v10：中文表达规范v4为写作、精修共用的语言标准；humanizer只执行局部修改，自审只定位问题。writing-dna已合并进写作入口并从资源目录移除，来源归属随合并保留。

newsroom-v11叙事模式v2：五部分指导模式选择、信息推进与复杂材料组织；结构设计落实本篇取舍，自审复用已有检查，不增加流程节点。

newsroom-v12结构设计v2：承接新闻承诺，将阅读理由落实到开头、传播依据安排在明确位置；具体手机首屏由发行预览检查，正文配图仍优先原图。自审复用结构检查，不新增节点。

newsroom-v13 humanizer基于blader/humanizer改编，并吸收humanizer-zh句法诊断；新增写作任务提交前必读。涵盖模式症状、改写动作、保留条件、八类翻译腔及事实等价示例，模型在同一任务内诊断修复。版本与原文hash见provenance，MIT全文随包保留。

newsroom-v17：新理解与选题按冻结授权调用web_search，背景并入理解底稿，不新增Agent；参见workflow与context-research，历史链和重试权限保留。

newsroom-v19：目标读者规范只保留目标人群、知识假设与阅读目的；写作原则归feature-writing，发现/证据/意义/限制归作者自审的内容检查，不规定固定章节。

newsroom-v21：主编面向AI × Biology/Pharma读者决定中心问题与新闻角度，作者决定细节和结构；reader提示关键理解障碍，不缩小为同行。选题可按需补查立项背景及普通读者理解主线必需的解释背景，交接真实来源；不假定理解包、报道历史或后续搜索能力存在。must_answer优先仅表达中心问题，最多三项，不展开独立子问题。已有冻结任务与编辑裁决边界保留。

newsroom-v23：任务书验收从本篇question/angle推导，先说明读者应理解的变化及依据，再保留影响主线判断的事实边界，不用论文事实清单或通用禁令代替报道目标。1200–1800字仅参考，不要求固定小标题数量或开头段落位置；只有输入注明来源的人工或渠道硬限制才作为硬要求。作者与编辑同步区分参考建议与核心验收，不改旧冻结任务。

newsroom-v24：主编与作者用save_background_research保存背景调研中间文档，包含问题、为什么查、真实答案与出处、缺口处置及是否足够的自评。可先存计划再更新结果，允许零搜索/零新增问题，不凑条数；同任务继续，不新增研究阶段或审批。真实文档随交接复用，后台可读版本与准确原文、下载Markdown；历史缺失不补造。

newsroom-v25：作者围绕读者理解任务组织句段，先解释设计理由再介绍必要术语，以材料取舍和真实承接替代逐条扩写底稿；中文规范v5明确句法、转场与就近限定。reader-explanation提供原创假设示例，自审定位理解缺口，最终检查保留分母、参照和集合关系。去除内容角色的固定引文条数及逐项答题倾向，不增加Agent、阶段、风格硬门槛或检测器评分。真实迭代与限制见本地data/reports/writing-quality-20261104，不能将程序提交成功等同成稿质量通过。

newsroom-v26：首轮真实作者未加载结构与解释资源，故将structure-design、reader-explanation和final-check纳入新写作任务已有的必读资源校验；按阶段渐进读取，不新增风格或篇幅裁决。旧冻结任务不回填。

newsroom-v27/v28：真实稿仍堆叠术语与结果后，明确导语只打开故事、正文按理解用途选择细节；补充连续叙述示例，展示如何把实验目的、结果和就近限定写成自然段。不把方法名称齐全视为严谨，不承诺仅靠规则消除所有模型文风。

newsroom-v29：以DR-GEM正式稿和StriMap产出审查通用性。中文规范v6改为按信息用途取舍，不再列单篇实验细节类别；解释资源改为跨类型假设示例并包含必须保留细节的反例。最终检查只保留对象、比较口径、分母、条件及范围等通用不变量。多组证据按判断组织，主编不为未提出用途预设免责验收。未新增阶段、权限或必读路径，新版真实生成效果尚未验证。

阅读品质由reader-editing独立任务承担，ReaderReviewReport/reader_reviews保存准确版本结论；两项方法共用一次阅读，新任务默认5次、最多10次的全流程共用作者返修额度，事实核验仍独立。新链reader-quality-v1，不回填旧历史；详见docs/reader-editing.md与ADR-101。

newsroom-v34：评审业务结论统一为通过或要求返修。阅读两项分别呈现通过/返修，事实blocking仍交作者修订；旧第三种结论仅保留历史读取，工具/读取异常与内容评审分开，额度耗尽保留未通过而停止自动调用。

newsroom-v64：刊会与主体核对服务于报道归属和核心进展，取消旧 v36–v40 默认调查首页出版状态及交接接收事件的要求。不调查或交接发表状态及出版流程日期；详细规则见 standards/news-signals.md。

newsroom-v41：进一步区分可核实的常规出处与能改变读者关注判断的强信号，保留无强信号稿件的发现型切入。

newsroom-v42：用可核实的动作、对照或结果交接新闻承诺。作者以代表性证据组织正文，读者编辑检查跨段理解，事实核验检查标题与导语的证据范围，图文制作选用能解释承诺的原图。

newsroom-v52：返修工作集与局部提交，core/revision.md保存最小返修方法。原始调查资料按需恢复，未变稿件和引用由宿主继承，新稿仍独立审核。stage-working-set-v1取消6%/2%频繁压缩，采用60%/12%兜底；历史快照不变。

newsroom-v55：报道论文，核对稿件转述而不核验论文科学有效性；统一删除防卫性陈述要求，条件按是否影响当前句意取舍，结尾不强制交代局限。

newsroom-v57增加news-outline-v1，作者起草前在研究底稿outline保存有据的逐段新闻计划，允许全文微调；新任务缺骨架不能交稿。旧冻结任务不补跑。

newsroom-v61：主编在同一任务内主动补查，最终提交报道或不报道。报道的任务书交接唯一角度、可选事实边界和工作标题。作者从角度推导研究问题。事实核验可直接引用角度或已填写的边界提出要求缺失。作者和事实核验按具体缺口读取绑定证据。
