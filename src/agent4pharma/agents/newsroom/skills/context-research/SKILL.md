# 背景调查

输入当前研究问题、上游底稿、实际材料和额度，遵守[科研证据规范](../../standards/scientific-evidence.md)，先读[目标读者规范](../../standards/audience.md)。只补跨专业读者理解新闻主线及判断价值所必需的背景，不扩展为全面综述。
本技能由主编选题与作者研究/写作按需调用，不另排背景任务。主编用实际背景依据作决定并交接来源；作者将结果保存到研究底稿，随后继续写作。不重做已解决的问题。

## 问题驱动的调查

1. 把缺口改写成可回答的问题，区分改变“新在哪里”“为什么重要”或稿件角度的决策背景，以及普通读者理解主线必需的解释背景；后者缺失不自动阻断立项。
2. 每个问题选择最直接来源与检索方式。优先查询官方介绍、论文摘要页面、团队公开资料和相关进展，不获取其他论文全文。
3. 保存实际查询、来源身份、读取范围和结果。检索片段可支持其中明确表达的背景事实，必须注明片段范围；不得声称已读论文原文。
4. 建立必要的前序时间线和比较表。明确哪些条件相同，哪些数据只能并列介绍、不能排名。
5. 核对与报道有关的团队、机构、资助、商业关联；不靠作者姓名猜单位，不把公司新闻稿当独立评价。
6. 分别总结已支持的研究增量、作者主张、尚不能判断的部分；实际产业影响与可能用途分开。

绑定主论文是报道其方法、结果与观点的依据，沿用已明确的来源归属。外部背景只在会改变选题或稿件关键表述时核对出处。优先用可取得的原公告、原记录或原研究摘要。只能取得转引时，保留实际读取的出处和范围。多家媒体转载同一份新闻稿只算一个来源。企业公告可支持“企业宣布了什么”，行业采用程度须有相应证据。

用 evidence-check 核对稿件中的新颖性、数字比较和产业表述是否超出实际来源。资料足以支持当前表述即可结束，来源类型和数量按实际问题决定。

## 有界结束

决定新闻判断的关键问题及理解主线必需的解释背景已有足够依据时结束，不为背景完整扩展检索。连续检索只有同源转载时记录覆盖边界，不装作多方印证。
遇到核心冲突，保留双方实验条件和依据，交主编决定报道争议、缩小范围或延期。
额度耗尽输出已知、未知和下一步最有价值的查询，不用无限检索换取确定语气。
只有获授权的搜索、读取、采访或分析工具才可执行；没有全网搜索时标“仅本地/绑定来源调查”。

## 交接

主编和作者都使用save_background_research保存独立可读的背景调研中间文档，不只把背景结论塞进任务书或正文。可以先保存问题计划，再在同一会话调研并更新，不新增阶段、不等待人工确认。提交本阶段前保存实际产出及充分性判断；保存本身不是任务完成。上游真实文档从get_production_context.background_research复用，修改本任务结果时按expected_version追加版本。

文档包括：
- focus：本次背景调研服务的具体新闻主线或读者理解目标。
- questions：每项有稳定id、question、purpose（decision选题判断/explanation读者理解）、relevance（为什么影响本篇）、status、answer、findings、handling及assessment。findings使用kind=background与真实evidence_id/source_span；通过read_evidence取得连续来源，不用搜索标题冒充核实。
- status区分planned、answered、partial、unresolved、technical_failure、not_needed。只有实际有答案和依据才标记answered/partial；问题缺失、查无与技术失败分开。
- handling说明use、qualify、omit或block，assessment说明为何采用、限定、舍弃或构成核心阻断，而不是泛称“有待进一步研究”。
- sufficiency为in_progress、sufficient、limited或insufficient；assessment解释现有背景是否足以支撑本篇新闻判断和必要解释，哪些缺口不影响报道、哪些会改变核心角度。该字段是调研角色自评，不冒充独立核验或人工批准。
- research_scope记录实际使用的来源范围、复用上游、未查/技术失败及停止原因。原始查询与调用记录仍看执行追踪，不在文档补造查询或与来源的对应关系。

不按问题数、搜索数或来源数凑配额。已有材料足够时允许questions=[]，但须说明无需补查的理由。先存问题计划时用in_progress，产出齐备后再更新充分性；不把未来科研展望自动变成采编缺口。作者在写作底稿background中选择真正用于报道的已支持背景，避免重复整份文档。

主编将决定性背景随证据和文档交接；作者保存可供复用的补充调研，继续写作。充分性不足若能通过省略或限定处理，明确处置；主线无法成立才报告核心阻断，不为“背景全面”无限扩展。
后续补证以问题和证据版本为单位追加，不重跑已解决的问题；事实变化时指出受影响的结论。

## 本项目工具约束

只在宿主已授权的主编选题或作者研究与写作任务中使用 DSH 原生 web_search；每次一个查询、最多五条结果，每条摘要最多 800 字符，60 秒搜索超时。优先解决 1–3 个背景问题，最多尝试三次搜索；这是行为预算，硬边界由任务总时限约束。没有其他论文全文获取工具。
搜索出处由宿主保存为 web_search_snippet，随后从证据目录取得真实 ID 并局部读取后引用。失败不等于没有相关研究。
作者的read_bound_source可读取已登记搜索URL的公开网页正文，适用于配套解读等片段不足的关键来源；主编没有此读取入口。返回目录后用read_evidence定位实际文本，复用已存正文；此处不新增其他论文全文获取能力。记录来源关系source_relation（original_research/team_explanation/external_commentary/unknown），保留观点归属，不把评论当独立验证；网页正文仍放背景。受读取额度与任务时限约束，失败、未读和实际取得文本分开记录。
已有主论文事实直接继承，不重复论证或以未读图像为由降级。缺背景不阻断主论文事实的报道。
