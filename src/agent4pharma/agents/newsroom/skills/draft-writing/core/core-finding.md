# 找到新闻核心并检验表达

承接任务书角度与决定理由，用已有证据提炼具体新闻句：相对有依据的已有认识或做法，此次推进了什么，为什么值得读者了解。区分方法、结果与进展，明确各项材料是在解释变化如何发生、支持哪个判断，还是限定其范围；不按摘要顺序罗列贡献，不预设所有研究遵循同一推进路线。

核对新闻句的比较对象、支撑关系与证据范围；摘要已经讲清时直接复用，只为影响主线的实际缺口定向补读。检验报道表述，不承担科研真实性审查，也不为检验另做独立验证或强找反例。

- Held：新闻句与现有来源一致，进入结构设计。
- Morphed：发现新闻句过宽、背景归属不准确，缩小或修正表述后继续。
- Broken：新闻角度依赖来源没有说过的内容，回主编调整；不指称研究本身被证伪。

只保存核心句、证据定位和简短决定。没有戏剧冲突也可写出有价值的报道。
