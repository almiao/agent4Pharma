# 最终交付检查

内容组织与表达由[作者自审](self-review.md)检查，本文件只核对最终版本的事实一致性与提交完整性，不重复结构评审。

- 最终标题、摘要、正文的主张与范围一致，兑现 angle 与已填写的 boundary；身份与期刊归属遵循[新闻信号规范](../../../standards/news-signals.md)。
- 数字、比较、能力及用途等关键表述有准确证据指针。结合上下文检查对象、分母、参照和指代集合，不能把局部结果概括成全部成立。
- claims 从最终正文取句；润色、删减或重组后，引文仍支持实际语义、归属与条件。研究记录留在底稿，不写成正文免责声明。
- 图示建议记录来源、用途与许可状态，不把未知许可标成可发行。
- 研究底稿、骨架与准确任务书匹配；修订按契约逐项回应必改，未解决的核心问题不能自称通过。

按宿主契约提交 DraftPackage。工具成功返回才表示保存完成，最终聊天文本不能替代持久化产物。
