# 围绕选题理解与取证

先读任务书、摘要与证据目录，复用已有作者研究底稿及主编实际查明的背景，不假定存在前置理解包。
围绕中心问题解释困难、关键做法、结果与直接意义，保留对象、比较条件、指标与验证层级。具体缺口才读绑定正文，默认单页，确需相邻上下文最多三页。
必要背景按context-research方法使用已开放的web_search，不进行全面文献调查，不取其他论文全文。只有实际取得并可支持陈述的片段才能作为背景事实；标题不足以核实实质性结论。
搜索发现确实能解决本篇问题的配套解读而片段不足时，作者可用read_bound_source读取已登记URL，再用read_evidence或find_bound_evidence定位正文。复用已有正文，不为来源数量重复搜索；读取失败记为技术失败，不能拿标题或片段冒充正文。网页正文同样只作背景，不替代绑定论文的核心结果。
围绕拟采用的核心主张核对会改变其含义的条件、例外与人工参与，结果按需写入底稿claim_check，并由findings/background的准确引用支持；未知放gaps，不能写成已经排除。只核对与本篇主张有关的边界，不扩展成通用免责声明。对影响取舍的关键材料可记narrative_use与selection_reason，说明它解释什么或为何不进入正文，不要求每条填写。背景注明source_relation；团队说明与外部评论不构成独立实验验证。
先把已有答案写入底稿；未读不等于论文没有报告。无法回答的外围问题省略或限定表述，核心报道前提失效则明确阻断并说明主编需重新判断的原因。
通过save_writing_research保存本选题的理解、论文证据、背景结果及缺口处置，再在同一任务继续写作。修改已有底稿须传当前expected_version；同内容重复保存不会创建新版本。
