# 准确稿件返修

以当前稿、报道目标和未关闭问题为起点，遵循[共同编辑判断](../../../standards/news-signals.md)。先判断问题来自事实、材料组织还是局部表达，再选择必要的修改范围。保留仍然有效的内容；结构性问题可以合并、删减或移动相关段落，局部提交方式不限制编辑判断。

表达调整复用有效证据；改变事实含义时核对相关原文、比较对象、分母、条件与归属。底稿不是已通过的事实结论，未读范围不能变成论文不存在。

get_revision_context已交付当前稿、准确引用索引、问题和公共规范；其余底稿、背景和方法按缺口读取，不重新保存没有变化的研究。原文索引仍可用时直接复用，不为每句再次定位。

通过submit_draft_revision提交局部变化。original从原稿逐字复制且唯一，多个变化不能重叠；需要插入时替换包含相邻原句的片段。标题或摘要随事实变化更新，其余留null。宿主保留未改主张的引用；原句消失会移除旧主张，改写或新增的关键事实要在added_claims绑定准确证据，claim逐字复制replacement或未改正文中的原句，不能概括。修改表述的归属、范围或限制时也要检查证据，不把文字仍在当作语义仍然成立。

评审意见指出待解决的问题，示例不是强制文案。建议无效时采用其他有据的处理，逐项说明如何消除原影响或为何保留内容。修改后重读标题、导语及受影响的全文关系，确认报道目标、事实边界和阅读效果未受损；不能以执行建议或增加解释自认通过。正文只呈现新闻，处理理由留在回应中。提交后仍须独立评审，成功提交即结束。

新任务复用已保存outline。局部表达调整不重新规划；主要结构、关键判断或材料依赖实质变化时，通过save_writing_research更新骨架后交稿。历史冻结任务没有骨架策略时不强制补写。
