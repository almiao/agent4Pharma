# 作者自审

完成初稿后，合上底稿只读成稿：读者能否理解重要变化、支持依据及必要边界？按[结构设计](structure-design.md)检查材料主次与推进，再按[中文规范](../../../standards/chinese-news-style.md)诊断表达。局部难懂时先判断成因，选择取舍、重组或解释，不默认扩写。

核对主张的依据、比较条件、因果关系及前后范围。事实疑点按 evidence-check 定向补查，不能凭记忆通过；事实或核心任务缺失不能靠润色解决。标题与导语须准确代表最终正文，修改后检查受影响的上下文。

简记实际问题及处理，不重复运行一套评分或章节检查。自审不能替代独立阅读评审和事实核验。
