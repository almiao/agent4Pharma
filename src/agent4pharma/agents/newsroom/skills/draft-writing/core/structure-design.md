# 本篇文章的结构设计 v2

## 一、职责与输入

将已选的[叙事模式](../modes/science-news.md)落实为本篇材料的内容骨架，兼顾新闻价值、理解顺序与移动端阅读。输入为主编任务书、新闻核心句和已有证据；输出保存到作者研究底稿outline，供本次起草使用，不新增大纲确认节点。

承接批准的 angle、可选 boundary 与作者研究问题，决定各部分回答什么、使用哪些材料、放在哪里及哪些信息需要原图帮助理解。不重新选题，不因论文包含多个贡献就扩大报道范围。

信息推进遵循叙事模式，标题与句段表达遵循[中文规范](../../../standards/chinese-news-style.md)，事实边界遵循[证据规范](../../../standards/scientific-evidence.md)。具体选图与页面呈现交发行角色。已有保存的有效骨架直接复用；没有已保存骨架时先保存，再起草。

## 二、开头安排

按所选模式确定导语与正文起始部分优先呈现的信息，以及理解它必需的上下文。将角度对应的读者收益落到开头，让读者尽早理解本篇值得继续读的理由；不要求开头完成全文摘要。

结果新闻可先交代关键发现，解释稿可先交代当前问题；具体方式依叙事模式，不统一从论文背景或团队介绍开始。检查必要信息是否被模型名称、机构、缩写、数据集和指标挤到后面，按读者理解需要延后次要内容。不故意隐藏关键结果制造悬念。

这里安排内容优先级，不承诺固定像素或字数的“首屏”。实际首屏受设备、字号、标题长度和图片影响，由发行环节的手机预览检查。

## 三、主体与材料取舍

承接已核对的核心进展，按读者理解它所需的关系安排材料：已有问题如何关联此次变化，关键做法如何关联结果，证据支持哪个判断或限制其范围。按本篇实际需要取舍，不把这些关系固定成章节或统一的研究路线。骨架中每部分只需简记：

- **回答的问题**：读完后读者新增什么理解。
- **关键材料**：支持、限定或改变该判断的已有实验、比较、数据或背景，优先引用已有证据身份。
- **位置原因**：为何在这里出现，与前后部分怎样推进理解。

每个主要部分解释一个与报道目标有关的关系或判断，按信息的重要性与理解成本选择展开程度。删减、概括、展开和重组都是可用手段；比较对象、关键条件与重要例外不能因简化而失真。材料可以逐项展开，也可以合并，依据是各自的解释作用，不是论文顺序或字段类别。

位置原因说明这一部分怎样推进理解，不仅描述“先背景、再方法”的顺序。只看各部分的核心内容，读者应能连起重要变化与依据；若只能列出实验或概念，应重新组织。开头方式、篇幅与章节由本篇需要决定，不为某种贡献类型套固定路线。

篇幅和分节按讲清主线的需要安排。不同证据承担不同解释任务时，可以逐项展开。只有任务输入明确注明来源的人工或渠道硬限制需要满足；参考篇幅、默认分节及段落位置不单独构成退稿理由，不因任务书复述默认值就把它升级为硬限制。

## 四、分节与视觉需求

正文需要依次完成不同的解释任务时，默认按读者需要理解的关系分节。同一问题可以用多个自然段回答。短讯或可以一气读完的单线报道可以不分节。按内容决定分节数量和位置，不套用论文目录。

为每个计划分节拟一个能让读者预知本节内容的小标题，记录在骨架该节首段的 section。小标题可以点出具体问题、结果或转折，措辞遵循中文规范。小标题应准确概括本节内容，所辖各段应围绕本节主题展开，包括必要的解释、证据、限定与衔接。成稿后核对标题与内容是否一致；不一致时，按报道需要调整标题、内容或位置。

识别原图能够帮助理解的内容，例如关键结果与对照、重要能力变化或难以用文字说明的机制。在相关部分标注希望读者看到什么、图承担证据还是解释用途；不强制每节配图，不默认方法架构图为首图。

优先使用绑定论文原图。原图不适合时优先建议换合适原图、改用文字或不配图，不把重绘正文示意图作为默认补救；自制封面另行处理。实际选图与图注走发行已有工具，结构设计不执行图片制作，不假定后续自动具备任意裁切、重绘或授权确认能力。未查看图片时只提出视觉需求，不声称图中具体内容已核验。

## 五、短骨架

起草正文前，必须通过save_writing_research的outline保存本篇结构决定：

- **主线**：承接的新闻承诺，不另起选题。
- **开头**：优先呈现的信息与必要上下文。
- **主体部分**：各部分的问题、关键材料和位置原因。
- **视觉需求**：确有需要时，注明原图应帮助读者理解什么。
- **收束**：本篇最终落在哪个有依据的判断，回应原承诺。

收束方式依叙事模式，具体语言依中文规范；核心问题已回答可以直接结束，不为骨架凑总结段。不固定章节或段落数。paragraphs按计划自然段排列，每段记录question、message、position_reason及sources；sources给实际evidence_id/source_span、已登记location和本段use。过渡段可依赖前文depends_on段号。可选visual_need和omissions只记录实际需要。已有保存的有效骨架直接复用；写作允许微调，实质改变结构或证据依赖时更新底稿。

### 局限的取舍与收束

底稿保留核对记录，成稿按新闻问题选择材料。结尾在新闻问题得到回答时自然结束，无需交代成果与局限的关系。条件确实影响当前陈述时融入相关事实句；常规研究局限、未独立复现、未涉及用途与核验过程不进入正文。删减不得把局部结果写成全面成立。

限制本身构成新闻主线或解释关键结果时，可以展开其具体影响；有实际来源分歧时准确交代。不为显得谨慎而追问论文没有承诺的用途，也不以列出风险、未解问题或后续验证作为报道完整的标志。
