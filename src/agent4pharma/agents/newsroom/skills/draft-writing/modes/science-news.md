# 科研新闻叙事模式 v2

## 一、职责与选择依据

承接主编批准的新闻承诺，决定从哪里切入、主要部分怎样推进理解、在哪里收束。目标是让读者逐步理解核心问题，不按论文原始章节复述研究过程。

先读任务书 angle 和可选 boundary。已指定报道类型时按其执行；未指定时根据新闻承诺选最匹配的模式，不按学科、是否提出模型或是否包含实验决定。

主线由任务书批准，核心句由写作已有材料承接。本文件选择推进方式，不重新选题；材料无法支持核心承诺时，按[写作入口](../SKILL.md)的恢复规则处理，不靠叙事制造结论。

本文件指导主要部分之间的信息关系；具体句段衔接与语言品质遵循[中文规范](../../../standards/chinese-news-style.md)，事实与结论范围遵循[证据规范](../../../standards/scientific-evidence.md)。本篇材料取舍、小标题、篇幅分配和证据位置由[结构设计](../core/structure-design.md)落实。以下均不是固定章节或额外工作节点。

## 二、四类模式

| 类型 | 核心新闻承诺 | 切入与推进 | 收束方向 |
|---|---|---|---|
| 结果新闻 | 出现了什么值得报道的新结果或能力变化 | 核心结果及其意义 → 关键证据与必要比较 → 理解结果所需的方法或背景 | 已支持的影响及关键边界 |
| 方法进展／方法解读 | 新解法如何改变一个具体瓶颈 | 瓶颈与已经实现的变化 → 关键设计思想 → 检验设计的结果、条件与代价 | 在哪些任务和条件下有价值 |
| 解释型报道 | 一个当前问题应如何理解 | 当前问题与解释价值 → 必要概念和证据 → 对已有认识的澄清或修正 | 当前可以作出的判断及未知 |
| 争议／评测 | 一个具体评价命题是否成立 | 待判断命题 → 可比证据及评价条件 → 差异来源与证据支持的判断 | 判断范围及剩余未知 |

表中箭头表示信息优先级，可根据材料调整，不要求逐项设节。

- **结果新闻**：读者应尽早知道最重要的结果。按各项证据对该结果的作用组织，不照论文实验或图表顺序排列；无需先介绍全部模型架构。
- **方法进展**：尽早交代已经实现的变化，重点解释有区分度的设计思想，常规组件按需压缩。只展开会改变价值判断、且材料支持的收益、条件或代价；不要求性能、成本、泛化等维度全部齐备，不因架构复杂就预设效果更好。
- **解释型报道**：每个概念和案例服务于任务书中的当前问题与新增理解，避免百科式展开。不必伪装成最新突破，也不能用“值得科普”替代主编已经批准的阅读理由。
- **争议／评测**：围绕真实且有证据可评价的命题展开，不先宣布胜负；条件差异可能比排名更重要。可以报道已有复现结果，不承担科学复现或论文有效性评审，不为阅读张力虚构对立或强行给出确定结论。

## 三、主要部分之间的推进关系

在所选模式内，可用以下关系让后一部分回应前文产生的问题：

| 推进关系 | 读者理解怎样前进 |
|---|---|
| 问题与回应 | 这个难题是什么，研究如何回应它？ |
| 结果与依据 | 发生了什么变化，哪些证据支持这个判断？ |
| 预期与实际 | 已有认识或预期是什么，真实结果有何不同？ |
| 方法与检验 | 关键设计为什么可能有用，结果是否支持？ |
| 能力与边界 | 已经做到什么，这个结论适用于哪里？ |
| 证据与判断 | 不同材料各自说明什么，合起来可以判断什么？ |

可组合少量合适关系，不要求全部出现。预期、反差和争议必须来自材料，不人为设置一个容易推翻的旧观点。方法说明、背景和限制应在读者需要它们理解当前判断时进入，不把“局限”固定藏在最后。

每个主要部分承担新的理解功能；必要回顾应帮助新的解释，不能反复换词重述同一结果。局部衔接怎样写交表达规范，具体哪些材料放进这一部分交结构设计。

## 四、多贡献论文如何选组织方式

以下是假设材料示例，不提供可直接引用的新闻事实。一篇研究同时提出模型、建立评测基准并开展实验，整体模式取决于已批准的新闻承诺：

- 承诺是“实验验证取得新结果”：采用结果新闻，模型和基准用于解释结果如何得到及其支持范围。
- 承诺是“新评测揭示现有模型的问题”：采用争议／评测，围绕评价命题比较证据，不按模型介绍、基准介绍、实验介绍平铺。
- 承诺是“新方法减少完成同一任务所需的实验”：采用方法进展，说明瓶颈、关键思想及材料确实支持的实验节省与条件，不能由基准提升推导节省成本。

不同贡献可以共同支持一条主线，也可以递进，但不要求全部介绍。整体模式保持一致，局部可解释方法或比较结果，无需每出现一种材料就切换报道类型。结构设计据此决定本篇保留哪些材料、如何分配篇幅和安排小标题。

## 五、篇幅与收束

短讯是篇幅形式，可承载上述主题：保留核心信息、关键依据和必要边界，省去外围背景与次要展开。长稿可充分解释关键问题，不因篇幅增加而强行添加章节。实际篇幅与分节依任务书及结构设计。

收束回应核心新闻承诺，可落在已支持的影响、方法适用范围、认识修正或下一项关键验证。条件与限制应靠近它们所限定的判断，结尾不必再次汇总；不强制行业展望、意义升华或固定总结段。

模式落实情况由已有结构检查与作者自审核对，不新增逐项打分或单独复审。

核心原则：以已批准的新闻承诺决定信息优先级，让每个主要部分推进读者理解；论文顺序和固定模板都不决定成稿顺序。
