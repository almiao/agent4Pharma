# 主张核验

输入准确表述、上下文、来源版本和用途；先读[科研证据规范](../../standards/scientific-evidence.md)。
核验单位是主张及其条件，不是整篇文章的总体可信分。

## 执行

1. 提取会影响新闻结论的主张：标题、导语、关键数字/比较、能力、因果、临床与商业结论、重要图注。
2. 分辨它是观察事实、作者主张还是本文推断。预测不能按已发生事实判真，但仍需核对依据和限制。
3. 找到直接原文并读必要上下文。逐字引文存在仅证明引用成立，继续检查是否真的支持该句。
4. 核数字的单位、分母、基线、样本、实验和版本。检查有没有跨 Figure、跨任务或跨论文拼接。
5. 记录稿件与来源的支持、冲突和缺口；检查表述是否越出原文的条件和验证层级。
6. 针对稿件的具体失真给出修正：纠正数字或归属、收窄错误主张、删除无依据内容。确需补充条件时说明省略造成的具体误解，不对论文观点另加保守性声明。

## 记录格式

claim_id；准确表述/正文位置；稿件版本；证据指针；实际核对范围；支持/冲突/缺口；
结果 supported / qualified / insufficient / contradicted；建议动作及满足何种证据才可解决。
supported 的含义是“指定材料支持该表述”，不等于原研究已经独立复现。

## 复用与停止

同一主张、来源版本、用途和语义条件不变可复用记录；改写扩大范围或换证据后重新核验。
核心结论缺证时不能靠“可能”掩盖，应转调查或重定选题；外围无法核实内容可以删去。
没有足够证据时交付 insufficient，不强求真假评级。不对论文的统计方法或研究质量另行发起审查。
编辑调用时也扫描作者证据清单之外的重大主张，避免作者漏标导致漏审。

## 当前项目执行口径

本项目以论文内容为事实基础，核验稿件与来源的一致性；不主动评审实验设计、真实性、复现或替代科学解释。摘要支持其明确陈述的发现，无需全文核验才允许报道。
