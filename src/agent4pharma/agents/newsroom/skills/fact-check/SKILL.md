# 事实核验

## 范围与方法

遵循[共同编辑判断](../../standards/news-signals.md)、[证据规范](../../standards/scientific-evidence.md)与[目标读者规范](../../standards/audience.md)。核对当前准确稿件实际提出的主张、比较关系、归属和范围，不审查论文科学有效性，不代替阅读评审决定表达与结构。

先核对标题、导语与核心判断，再检查其依据及影响结论的条件。任务覆盖关注报道承诺是否获得实质支持，不以任务书或底稿材料是否全部出现判断完整性。作者可自行选择支撑细节与组织方式。

作者底稿和 claim_check 仅作定位线索；优先复用准确引文窗口，按缺口补读上下文。外部评论、团队说明不能提升为独立验证；未读到不等于论文未报告。来源已建立时不要求每句重复归属，也不脱离上下文把稿句解释成更强主张。

检查行动主体、预测与观察、比较对象、数字分母和实验条件是否一致。机构角色与期刊身份以来源为准；核对稿件对论文内容的转述，不检查发表状态，归属规则遵循[新闻信号规范](../../standards/news-signals.md)。省略条件只有在改变当前主张的范围或造成具体误解时才必改；不得因底稿包含某项材料就要求补回，不新增论文未承诺的评价维度。

## 问题单与提交

业务结论仅 pass 或 changes_requested；有 required/blocking 即返修，blocking 仅表示严重性。无必改时 issues 为空，summary 记录核验范围与结论，不加入表达偏好。通过不表示发布。

- factual_error：draft_quote 逐字复制准确稿句，evidence_id/source_quote 给出绑定来源的连续纠正原文，说明具体冲突、虚构或越界。
- requirement_gap：requirement 逐字复制准确任务书 angle 或已填写的 boundary，说明核心承诺未满足或关键边界缺失，不能把措辞偏好包装成要求缺失。

问题保持稳定 ID，给出可核验处理条件；作者可以纠正、收窄或省略，不要求补造证据。工具或读取失败单独 report_production_blocked，不伪装为业务结论，不另设重选题或等待人工出口。

## 复审

核对前轮必改及实际改动的事实影响；已解决问题沿 ID 关闭，新问题须有新引入的实质错误及准确依据。前轮建议不能覆盖来源，方案无效时修正处理要求，不为维护建议放行，也不对已认可且未改动的内容展开偏好竞赛。成功提交即结束。
