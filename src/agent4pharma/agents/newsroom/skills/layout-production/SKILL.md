# 科研新闻图文编排

输入是通过审核的准确稿件与绑定论文资料。输出为定稿正文、原图选择清单、网页 HTML、公众号正文片段及可追溯记录。

## 业务步骤

1. 先读定稿，按[共同编辑判断](../../standards/news-signals.md)确定图片的解释或证据用途。选择与相关段落主张一致的图；醒目程度和可获得性不改变内容主次。不重新审核论文真实性，数量按实际用途取舍。
2. 从已有论文缓存按需查图页和相邻图注。图块编号不是论文图号，必须目视核对原图里的面板标签、坐标、组名，再核对图注。
3. 选择完整子图；保留坐标、图例、统计标注和必要上下文。多面板大图优先使用缓存中已经分出的完整子图，手机上纵向排列，不把整页缩成缩略图。不生成或重绘实验结果。
4. 每幅图记录 evidence_id、PDF page、block、after_paragraph（非空正文行从1编号）、label、caption。图注只讲原图及准确对应图注可证实的内容；不得凭邻近其他面板补充测量方法（如把RNA热图称为流式细胞术读数）、基因型或实验条件。没有清晰对应依据则省略该细节。不能把计算示意称为实验结果。没有核对过的图不进入清单。
5. 正文按定稿逐段保留；标题同定稿。默认白底深蓝标题、系统中文字体、单栏、正文17px/1.95行距、手机左右20px留白。图按自然尺寸显示，上限100%，小图不强行拉伸。不要新增卡片墙、渐变、装饰图或每段小标题。封面可另行生成，不是每篇必需。
6. 由宿主固定模板生成两种产物：完整网页文档，以及仅内联样式的公众号正文（公众号标题单独填写）。不得用模型生成可执行脚本或外部图片地址。
7. 在390px和桌面宽度实看；检查文字横向溢出、原图加载、图中文字可读、图文对应及正文一致性。仅修排版问题，不触发措辞/过渡返工。图不清晰时换完整子图或舍弃，不用放大模糊图掩盖问题。

## DSH选图工具与提交

1. get_production_context取得定稿和绑定论文evidence_id。不要重写稿件或重启审核。
2. find_paper_figures(evidence_id, query)用定稿核心概念的英文关键词定位图页；一次最多3页，最多6个不同查询。同查询只回已返回标记；不同查询命中已返回页面时也只回reused_pages，复用之前的目录，不重复倾倒同页内容。页码已知时用page限定。
3. inspect_paper_figures(evidence_id, figure_ids)返回真实图片；pN是该页带子图ID的缩略图索引（只供定位），pNbM是子图。推荐先查看1个最相关页的缩略图索引，直接读出图上印着的pNbM，再查看拟采用的2–3个完整子图。不要把原文面板a/b/c或g的字母顺序推测为block编号。每次最多3图、总共6图，已看过的图不重传。不要依次查看每页，也不要一次取全篇图像。
4. 看图工具报错最多重试一次，仍失败则report_production_blocked，不能提交无图包冒充选图成功。若收到图像不支持的诊断，报告阻断，不用图注假装看过图片。收到图片后识别实际面板字母、坐标/图例、组名；邻近OCR只是定位线索，不保证图块和面板一一对应。
5. 按上述用途选择图片；同类实验面板优先选代表性一张，不为凑数重复。每幅图须实际看过准确子图，完整保留必要坐标和图例；缺失必要色标、坐标或图例的子图不要选用（例如热图有刻度但没有列名称，不能自行把列解释成细胞状态），不能用图注承认缺失来代替完整性要求；总览只能辅助定位，不能提交整页当插图。
图注提交前逐项对照准确子图：横轴组别必须按从左到右顺序逐字读出，区分单杂合与双杂合，不用相邻图注猜测。看不清、标签缺失或visual_observation含“另一组／未能辨读／推测”时，放弃该图；不能把不确定性藏在后台而在正文给出确定组别。不写未证实的误差棒定义、红圈含义、样本单位，不凭常见画法猜均值或单只小鼠。图注只保留清楚可见并有来源依据的信息，避免无必要坐标范围和点位近似值。

6. submit_channel_package提交local_html、release_note和figures。每项包含evidence_id/page/block/after_paragraph/label/caption/visual_observation。visual_observation留后台，记录你实际看到的标签、坐标、实验分组或图中数值，不能只写“看过”或复述本文摘要；正文图注不得混入操作日志。
7. 成功提交立即结束。宿主从缓存复用已查看原图，确定性渲染并保存新包，原稿和审核不变。不需要再请求旧的HTTP制作接口。

查询/看图分别计独立额度；不要消耗正文读取预算或读取全文。缺少合适图片可以明确说明并提交无图包，不能伪造图像。当前图目录是缓存一次建索引，后续查询不重新扫描PDF。

## 复用说明

本技能和模板是按本项目约束新写。调研参考了通用阅读设计与公众号技能的“内容与渲染分离、内联样式、手机预览”做法，未复制上游技能正文、组件或脚本：
- https://github.com/pbakaus/impeccable
- https://github.com/isjiamu/gzh-design-skill
- https://github.com/843645440/wechat-skill

禁止为了追求版式而改变数字、删研究限制、重造原图。未经验证的图片复用许可保留为未知，不把本地导出称为外部发布。

保留写作阶段已提交的“## ”小标题，由宿主渲染为h2，不自行新增或重写。after_paragraph按所有非空行计数，包含标题行。优先主线结果图，方法图仅在确实帮助理解时使用；不能让方法图挤走核心结果。

可按需提交emphasis={source_body_hash,items:[{paragraph,quote}]}，source_body_hash复制get_production_context.draft.source_body_hash；paragraph同样按非空行从1计数，quote为该普通段落内唯一的准确连续文字。宿主只增加strong标记，不改正文。优先标注能帮助跳读理解的关键判断，保留改变含义的条件和否定，不拆出夸大结论；无需每段加粗，不按条数验收。标题行无需额外强调，重复、重叠或过期标注会拒绝。重点标注只支持local_html，网页与公众号片段同步生成。原图继续紧随它实际解释的段落，不能仅以视觉间隔为由配无关图片。

先读[目标读者规范](../../standards/audience.md)，保留已审定的术语解释、图注与科学限定；不重新定义受众或为通俗化改写定稿。

选首图时看它是否能让读者看见标题与导语承诺的对象或结果。图注交代这一幅图能看见的动作、比较或结果，保留必要条件，省去正文已经说清的背景与结论。若图展示的是架构、仿真或实验示意，明确说明其性质。
