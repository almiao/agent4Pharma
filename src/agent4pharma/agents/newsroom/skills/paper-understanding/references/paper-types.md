# 按贡献类型理解

只使用与本篇有关的追问。混合型可组合；摘要未提供的内容不凑齐、不推测。

| 类型 | 应当讲清的关系 | 避免的混淆 |
|---|---|---|
| method 方法/模型 | 输入输出 → 原有瓶颈 → 关键做法 → 结果成立条件 | 方法名称不等于工作原理，基准改善不等于落地 |
| discovery 发现/机制 | 观察现象 → 实验/分析证据 → 支持的解释及范围 | 相关性不自动成为因果，机制假说不等于已证实 |
| resource 数据/资源 | 缺什么资源 → 新增覆盖与使用方式 → 质量依据 | 数据量大不等于代表性充分 |
| evaluation 评测/负面结果 | 检验什么主张 → 比较设置 → 得到什么边界 | 特定设置的失败不等于方法普遍无效 |
| translation 实验/转化 | 对象与干预 → 对照/终点 → 验证阶段与结果 | 体外、动物、临床阶段不能互换 |
| review 综述/观点 | 当前问题 → 综合的证据或论据 → 核心观点 | 不把综述论点写成新实验或领域共识 |

## 对照示例（假设材料，不是论文事实）

方法论文，材料说模型用重构误差定位未学好的样本，并在给定测试上改善少数群识别。
- 差：提出全新自监督框架，全面提升性能，具有巨大应用价值。
- 好：多数样本可能主导整体拟合；该方法用重构误差寻找没有被学好的样本并调整学习关注。作者在指定测试上报告少数群识别改善；是否适用于其他任务尚需对应证据。

机制论文，材料只有某基因表达与表型的相关分析。
- 差：发现该基因控制疾病，可开发新药。
- 好：作者观察到该基因表达与该表型相关，为后续机制研究提供线索；现有材料不能支持因果或治疗效果。

观点论文，材料提出科研Agent评测框架。
- 差：新Agent实现自主科研突破。
- 好：文章提出如何评价科研Agent的框架，贡献是评测问题与组织方式；并未报告新的自主实验结果。

意义段同样需要来源：材料只报告少数类识别改善，可以解释为帮助分析者保留容易被忽略的信号；不能添加“无需人工处理”或“无需额外实验”，即使加上“可能”也不成立，除非来源明确支持这些前提。
