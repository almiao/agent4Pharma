# 新闻吸引力与阅读推进评审

## 判断方法

吸引力指读者知道本篇为什么值得读，并不断获得与新闻承诺相关的信息，不预测点击或转发率。不用夸张、焦虑、故意扣住结果制造悬念。

初读全文后检查：

1. 标题与开头：具体对象发生了什么变化？为什么值得当前读者知道？机构、期刊、缩写或评价是否代替了新闻本身？阅读理由是否被次要背景挤到后面？不机械限定第几段或首屏。
2. 解释顺序：读者理解当前结果所需的对象、任务或比较关系是否已经建立？技术名、指标不能承担尚未完成的解释。可以直接进入结果或具体测试，不强制所有稿件从困难开场。
3. 材料主次：关键证据获得解释，还是多个实验平均报数？数据是否帮助判断幅度、条件、重要例外，还是只证明作者看过论文？同类细节按用途取舍，不按字段类别统一删除。
4. 段落推进：后一段是回答前文自然产生的问题、补充证据、比较或限定，还是仅追加另一个结果？缺逻辑时应重排或取舍，不能统一加“更重要的是”。复杂解释允许几段完成，不要求每段新发现。
5. 信息节奏：是否把功能、机制、全部结果、限制挤进一个内容单元？关键处有没有解释空间，常规内容是否反复停顿？不靠把长段机械拆短改善。
6. 收束：是否继续回答新闻主线，还是突然变成局限性清单？技术细节有没有说明对核心成果的影响，还是要求读者自行归纳？最后是否形成明确认识，还是停在无关的来源覆盖检查？确实影响判断的条件应保留并就近放置，不为谨慎追加免责声明，也不强制追加成果总结。

只读各部分的一句概括，应能连成中心问题的答案。若只是背景—方法—实验一—实验二—讨论，继续判断组织是否实际服务这篇；章节名本身不是罪证。

对有多个解释任务的正文，再跳读一遍。检查读者能否快速找到核心结果、理解结果所需的解释及支撑它的证据，并看出各部分怎样衔接。小标题能否准确预示本节内容，所辖段落是否围绕本节主题展开？不能仅因内容有依据、与全文主线相关，就认为其当前位置合理。分节缺失、标题含混或标题与内容不匹配，确实造成内容范围误判、关键内容难找、关系难懂或明显打断阅读推进时，列阅读推进必改，用代表文字说明影响与应恢复的内容关系，不指定唯一改法。标题措辞的个人偏好不阻断；连贯易读的短稿可以没有小标题，标题数量不作为判定依据。

## 定位整体问题

围绕重要判断指出具体缺失的关系及阅读影响，不以“数字多”“标题平淡”代替诊断。跨段问题用必要的代表锚点解释共同原因；关闭条件与复核规则统一见[评审入口](../SKILL.md)，不另设一套验收要求。

正文已有足够解释时应认可，不因后台还有材料要求加长。准确的否定结论可以构成新闻，不要求改成正面评价。身份与刊会信号遵循[共享规范](../../../standards/news-signals.md)，其准确性留给事实核验。
