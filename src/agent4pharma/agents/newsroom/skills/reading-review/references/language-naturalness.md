# 中文表达自然度评审

## 从信息作用判断

以专业、直接、可顺畅理解的中文为目标，不要求像聊天。AI味、翻译腔、英文腔、论文解释腔是线索，不是错误类别或退稿依据。指出实际句法、叙述视角或重复造成的障碍；不判断文本是否AI生成。

| 线索 | 看什么 | 可能的修改 | 应保留的例外 |
|---|---|---|---|
| 翻译句法 | 长定语压住动作、多层被动、空壳动词和名词链 | 明确谁做什么，再安放条件 | 结果比主体重要、主体未知或专业定义确需限定 |
| 英文结构迁移 | 从英文抽象概念顺序逐词展开，术语排列代替实际关系 | 用中文先说清关系，再给必要名称 | 固定术语、科学标识符、准确概念区别 |
| 论文解释腔 | 反复“论文首先…作者随后…”而事物本身退场 | 用已知团队、系统、过程和结果作主体，按读者问题组织 | 讨论论文观点、争议、作者解释或引文归属 |
| 核验口吻外溢 | 每段都提醒“属作者主张”“本稿未验证” | 来源已建立后直接叙述结果与观点，删除防卫性声明，内部审计留后台 | 外部观点和实际来源分歧须准确归属 |
| 模板化模式 | 无信息反转、对称三项、段末升华、重复结语 | 删除包装，保留实际新增信息 | 真实对照、有信息的强调、确实三个项目 |
| 动作与指代含混 | “这一能力使其实现对相关过程的优化” | 补回已有明确对象和动作 | 对象未知时不能猜，需保持准确概括 |
| 过度包装 | 空泛惊讶、重要性报幕、无对象的辩解 | 直接提供信息 | 有来源且有解释用途的评论和争议 |

不建立“论文作者”“不是…而是”“同时”“因此”黑名单，不用同义词轮换制造自然。一个词通常不构成required；持续模式须有代表锚点及具体影响，合法修辞不要误伤。

## 修改的事实不变量

建议局部示例时核对主体、动作、对象、时间、数字和单位、否定、比较条件、因果、归属、确定性。不能把“团队认为现有路线存在局限”改成“现有路线无法使用”，不能把“相关”改成“导致”，不能将模拟测试改成真实现场。

需要新的事实才能让句子具体时，先建议收窄、保留概括或交作者核实，不编访谈与人物。必要限定保留不算语言缺陷；删除无关用途的通用免责声明与删掉实际比较条件是两回事。

required针对妨碍理解的含混/句法，或贯穿多个内容单元而显著遮蔽主题的论文/审计口吻。已经清楚的忠实转述从问题单省略，不因不够优美退稿。整篇结构不对时先按阅读推进评审重组，不能只替换“作者”为“团队”。

检查抽象名词连串、英文学术语序和正文里的审计口吻。若段落持续用“报告了”“所读正文”“这一设置下”等方式介绍材料，试着找出可以恢复的动作、主体和结果，区分必要的来源归属与反复记录查阅动作。仅当这类表达造成对象不清、论证难跟或持续打断阅读时列必改，并给出准确锚点。

导语或核心结果句也要单独检查。即使套语只出现一次，若它让关键动作退居从句、让读者看不出是谁作出判断或在哪项实验观察到结果，可以锚定该句列必改。准确且必要的来源归属可以保留；复核时看动作、证据边界与来源是否都更清楚，单换一个引述动词不足以解决问题。
