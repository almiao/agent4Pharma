# 模型交互配置

拥有提示词版本、草稿输入及发布时的并发校验契约。公开入口为 `prompt_contracts.py`。
不决定业务判断，不调用模型，不配置凭证、权限或输出结构。
各节点默认指令由 composition 装配，持久化实现使用专用仓储。
新增模型交互先登记实际调用用途，再接通冻结输入，不能只登记一个无消费者的页面条目。

公共编辑规范audience/scientific_evidence/chinese_news_style复用版本契约，默认正文来自newsroom/standards。
设置页统一新增草稿、编辑、对比和发布；装配将已发布正文及身份注入新链技能快照，各阶段按冻结资源读取。
正文与示例合计限制23000字符，为资源身份及hash留出冻结空间；不允许用户指定文件路径或修改工具权限。

共用主题标准及预选模板见 `screening_prompts.py`。PromptRepository 发布标准时通过同一工作单元
生成预选新版本，保留并发校验、阶段自定义指令和历史快照。旧情报精筛节点及配对发布已删除。
价值排序与商业整体比较分别注册news_ranking/news_comparison，默认正文来自news_selection，
通过同一提示词仓储编辑/发布。新运行冻结发布正文、示例及ID/hash，附加目标读者规范；旧运行按原快照续跑。
